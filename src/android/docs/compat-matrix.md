# 兼容矩阵

`minSdk` 为 24（Android 7.0）。下表列出随系统版本启用的功能，以及低于门槛时的表现。

## 系统版本门槛

| 功能 | 最低 API | 低于门槛时 |
| --- | --- | --- |
| 渐进模糊顶栏、磨砂卡片、模糊页面背景 | 33，且设备支持运行时着色器 | 顶栏使用不透明表面色，卡片使用半透明或实色，不进入模糊管线 |
| 流动背景（`BgEffectBackground`） | 33，且设备支持运行时着色器 | 只绘制内容，不绘制背景效果 |
| 平滑圆角（squircle） | 33，且设备支持运行时着色器 | 使用普通圆角 |
| Liquid Glass 底栏、卡片、滑块、开关 | 33 | 底栏和卡片使用常规样式；高级材质里仍可选 Liquid 但不生效，玻璃强度入口不显示 |
| 液态涟漪（`LiquidRipple`） | 33 | 不显示涟漪 |
| 起始页模糊过渡（`RenderEffect`） | 31 | 不应用模糊，其余动画不变 |
| 通知权限请求 | 33 | 不请求，视为已授予 |
| 莫奈取色（系统壁纸色） | 31 | 使用主题页所选的种子色或基准色 |
| 色板预览中的系统强调色 | 31 | 使用中性色 |
| 应用级深浅色同步（`setApplicationNightMode`） | 31 | 不同步，只影响应用自身界面 |
| 图片解码（`ImageDecoder`） | 28 | 使用 `BitmapFactory` 按采样率解码 |
| 显示模式读取（`Context.display`） | 30 | 使用 `defaultDisplay` |
| 帧率节能平衡（`setFrameRatePowerSavingsBalanced`） | 35 | 不调用，刷新率仍由显示模式偏好决定 |
| 颜色规范 2025 | 36 | 使用 2021 规范 |




## 预测性返回

`AndroidManifest.xml` 已声明 `enableOnBackInvokedCallback="true"`。三种模式：

| 模式 | 行为 |
| --- | --- |
| 关闭 | 由 `BackHandler` 直接返回上一页 |
| 官方 | 由 `NavDisplay` 处理系统预测返回 |
| 自定义 | 返回手势跟随手指位置 |

各模式在 API 33 及以下设备上的表现未验证。

## 设置页中的联动

- 风格为 Material 时，高级材质、玻璃强度选项不显示。
- 高级材质为 Liquid 且设备低于 API 33 时，主页背景的卡片材质不提供 Liquid。
- 构建时传入 `-Pzeroui.style=miuix` 或 `material` 会固定风格，设置页不再显示界面风格选项。
