# 更新與隱私

更新與隱私相關的選項位於 **設定 › 常規**。

## 更新

### 檢查更新與公告

正式版在啟動時獲取最新版本資訊與公告。該請求不攜帶任何裝置標識，所有使用者收到的內容相同。可以關閉 **啟動時檢查更新與公告**，並在需要時點選 **檢查更新** 手動檢查。

### 安裝更新

發現新版本後，Campfire 會先顯示更新說明並徵求同意。確認後：

1. 下載更新包；
2. 校驗更新包的**數字簽名**，只有由 Campfire 釋出金鑰簽名的檔案才會被接受；
3. 替換程式檔案並自動重新啟動。

若當前開啟了房間，Campfire 會提前說明更新將關閉房間。若程式所在資料夾不可寫入，或下載、校驗失敗，當前版本保持不變，Campfire 會開啟下載頁面供手動更新。

### 必須更新

當舊版本存在嚴重問題時，新版本可能被標記為必須更新。只有在簽名正確的新版本已下載並通過校驗後，Campfire 才會要求更新後再繼續使用；若下載或校驗失敗，Campfire 照常可用。

::: info 從原始碼構建的版本
自行構建的版本不會連線更新與公告服務，也不會發送使用統計。
:::

## 使用統計

使用統計用於瞭解 Campfire 的使用情況並改進軟體。它**僅在你同意後傳送**，拒絕不影響任何功能，也可以隨時在 **設定 › 常規** 中關閉。

### 傳送的內容

每臺電腦每天最多傳送一次，內容僅限：

- 統計標識：首次傳送時隨機生成，與連線使用的裝置標識無關，可隨時重置；
- 軟體版本、Windows 版本與系統位數、.NET Framework 版本、介面語言；
- 建立房間、加入房間、修復啟動器等功能的使用次數；
- 伺服器根據網路來源推斷的大致國家與省份。

點選 **檢視傳送內容** 可以看到下一次傳送的完整資料。

### 不會收集的內容

IP 地址、遊戲賬號與 UUID、玩家名稱、房間與邀請碼、檔案路徑、硬體序列號與網絡卡地址。你主動公開到連線大廳的房間除外，見[連線大廳](./lobby#隱私)。

### 儲存與用途

統計明細保留 90 天后自動刪除，此後只保留不含統計標識的彙總數字。資料僅用於瞭解軟體的使用情況和改進軟體，不會出售或提供給第三方。

### 撤回

關閉使用統計後，Campfire 不再發送任何統計資料。點選 **重置統計標識** 後，此前傳送的資料將無法再與這臺電腦關聯。

## 連線中的隱私

連線相關的隱私選項，包括隱藏 IP 地址、讀取遊戲賬號與共享皮膚，見[網路與隱私](./network#隱私)。

完整的隱私說明也可以在 Campfire 的 **設定 › 常規 › 隱私說明** 中檢視。Campfire 的全部連網行為見[連網與安全](./security)。
