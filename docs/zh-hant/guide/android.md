# Android 版

Campfire Android 版讓在手機或平板上遊玩 Minecraft Java 版的玩家也能建立與加入房間。它與桌面版使用同一套連線協定，手機與電腦上的玩家可以進入同一房間，邀請碼與連線大廳在兩端通用。

## 系統要求

- Android 7.0 及以上版本。
- 64 位元 ARM 處理器，近年的手機與平板均滿足此條件。
- 一款能夠執行 Minecraft Java 版的 Android 啟動器。Campfire 作用於正在執行的遊戲，不限定啟動器。

## 下載與安裝

1. 在[下載頁](/zh-hant/download#android-版)下載 `Campfire.apk`。中國大陸使用者建議使用國內直鏈。
2. 開啟下載的檔案。系統詢問是否允許安裝未知來源應用程式時，為瀏覽器或檔案管理器開啟該權限，再繼續安裝。
3. 首次開啟時，Campfire 會依次檢查系統版本、通知、背景執行與區域網路存取，並說明每一項的用途。

::: tip 背景執行
遊戲在前台執行時，Campfire 需要在背景保持房間連線。請允許 Campfire 在背景執行，並在系統的電池設定中將其設為不受限制。房間開啟期間，通知欄會持續顯示房間狀態，可從通知中複製邀請碼或關閉房間。
:::

## 介面概覽

| 標籤頁 | 內容 |
| --- | --- |
| 主頁 | 建立房間、加入房間、目前房間狀態與連線步驟；卡片可長按拖動排序，也可從主頁關閉 |
| 大廳 | 瀏覽連線大廳中公開的房間 |
| 設定 | 連線設定：玩家、網路、隱私、遊戲資料夾、房間與診斷 |

主頁右上角的按鈕通往 **應用設定**，其中包含主題設定、語言、更新與公告、支持專案與關於。

## 建立房間

1. 在 **主頁** 點擊 **建立房間**，再點擊 **開始**。
2. 回到啟動器，進入單人世界，並在遊戲選單中選擇 **在區域網路上開放**。
3. 連線 Wi-Fi 時，Campfire 會自動發現該世界並開啟房間；使用行動數據時，請改用 **手動輸入埠**，填寫遊戲聊天欄中顯示的埠號。
4. 房間開啟後，點擊 **複製邀請碼** 或 **分享**，將邀請碼傳送給其他玩家。

::: warning 需要手動在區域網路上開放
Android 系統不允許一個應用程式讀取或修改另一個應用程式的執行狀態，因此 Android 版無法像桌面版那樣自動在區域網路上開放世界，也不會在遊戲聊天欄與 Tab 列表中顯示房間資訊。退出世界後，房間會自動關閉。
:::

房間頁的 **工具** 卡片包含 **房間設定**、**公開到聯機大廳**、**白名單**、**語音** 與 **聯機診斷**；在玩家列表中可以將玩家移出房間或新增至白名單。房間名稱、人數上限與公告的說明見[房間管理](./room)。

## 加入房間

1. 複製房主傳來的邀請碼後開啟 Campfire，應用程式會詢問是否加入該房間；也可以在 **主頁** 點擊 **加入房間**，貼上邀請碼或整段聊天訊息。
2. 連線完成後，開啟啟動器進入遊戲，在 **多人遊戲** 列表底部找到 **Campfire 連線房間**，點擊進入。

邀請碼以 `U/` 開頭，共四組字元，與桌面版完全相同。房主使用正版帳號時，請從區域網路世界條目進入，而非直接連線房間頁中顯示的位址。

## 連線大廳

**大廳** 標籤頁列出所有公開的房間，桌面版與 Android 版的房間都會顯示在其中。房間帶有密碼時，點擊 **加入房間** 後需要輸入密碼。認為房間的名稱或內容不當時，可在房間詳情中檢舉。

### 公開房間

房主可以在房間頁的 **工具** 卡片中開啟 **公開到聯機大廳**，填寫房間介紹與密碼，選擇至多 3 個標籤，再點擊 **公開**。房間名稱沿用房間設定中的名稱，大廳顯示其前 24 個字；遊戲版本與世界名稱由 Campfire 自動讀取。公開後，房間的人數與語音狀態會隨時同步至大廳；房間關閉後自動從大廳移除，也可以隨時點擊 **取消公開**。

## 語音

房主在房間頁開啟語音後，Campfire 會為遊戲安裝語音模組 Simple Voice Chat，並為玩家轉發語音資料。語音需要以下準備：

- **授權遊戲資料夾**：在 **設定 › 遊戲資料夾** 中授權啟動器的遊戲資料夾。Campfire 能識別常見的 Android 啟動器，也可以選擇任意啟動器的 `.minecraft` 資料夾。Campfire 只讀取版本資訊，並寫入自己安裝的模組。
- **使用帶模組載入器的版本**：語音模組需要 Fabric、Forge、NeoForge 或 Quilt。
- **重新啟動遊戲**：安裝語音模組後，需重新啟動遊戲並進入世界，語音方可生效。

完整說明見[語音聊天](./voice)。

## 連線設定

**設定** 標籤頁即連線設定，包含以下內容：

- **玩家**：玩家名稱與遊戲內名稱。
- **網路**：允許中轉、隱藏我的 IP 地址、尋找房主的時限、識別剪貼簿中的邀請碼，以及 **中轉伺服器**。中轉伺服器頁面可測速、選擇內建伺服器或新增自訂節點。
- **隱私**：顯示正版玩家的皮膚頭像、向其他玩家顯示軟體版本，以及重置裝置標識。
- **遊戲**：遊戲資料夾。
- **房間**：房間設定與白名單。
- **診斷**：**聯機診斷** 逐項檢查系統、連線元件、網路連線、中轉伺服器、本機埠與區域網路世界，並給出處理建議；**聯機日誌** 記錄加入與建立房間的過程，可直接分享給他人排查問題。

## 與桌面版的區別

| 功能 | Android 版 |
| --- | --- |
| 邀請碼連線、連線大廳、房間設定、白名單、語音、皮膚頭像、聯機診斷、使用統計 | 支援 |
| 自動在區域網路上開放世界 | 不支援，需在遊戲中手動開放 |
| 遊戲內歡迎訊息與 Tab 列表資訊 | 不支援 |
| 模組同步、線上地圖、啟動器修復、JRE 啟用工具 | 不提供 |
| 連線元件 | 隨安裝套件提供，無需另行下載 |

## 更新與隱私

- **公告**：啟動時取得 Campfire 發布的公告，可在 **應用設定** 中關閉 **接收公告**。
- **使用統計**：首次進入主介面時，Campfire 會詢問是否傳送匿名使用統計，預設不傳送。允許後每天最多傳送一次，可在 **應用設定** 中關閉、檢視下一次傳送的內容或重置統計標識。
- **皮膚頭像**：房間內有正版玩家時，玩家列表顯示其皮膚頭像，可在 **設定** 中關閉 **顯示正版玩家的皮膚頭像**。
- **檢測更新**：預設關閉。在 **應用設定** 中開啟後，Campfire 會在啟動時檢查新版本；發現新版本時，點擊 **更新** 將在瀏覽器中開啟下載位址，應用程式本身不會下載或安裝任何程式。
- Android 版的全部連網行為見[連網與安全](./security#android-版)。

## 常見問題

### 自動發現不到我的世界

請確認已在遊戲中於區域網路上開放世界，且已在首次啟動或系統設定中允許 Campfire 存取區域網路。使用行動數據或部分公共 Wi-Fi 時無法自動發現，請改用 **手動輸入埠**。

### 玩家進入世界後很快斷開

多見於系統在背景限制了 Campfire。請在系統設定中允許 Campfire 背景執行，並關閉對它的電池最佳化。

### 無法加入房間

請先執行 **聯機診斷**。雙方網路限制均較嚴時可能無法直連，可在連線設定中允許中轉，或由網路條件更好的一方擔任房主。其他問題見[常見問題](./faq)。
