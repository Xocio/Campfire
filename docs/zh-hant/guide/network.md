# 網路與隱私

本頁介紹連線設定中的各個選項。連線設定位於 **設定 › 連線**，也可從主頁的 **連線設定** 磁貼，或點選標題欄的中轉伺服器指示燈開啟。

::: info
設定更改會即時儲存，並在下次建立或加入房間時生效。
:::

## 連線方式

Campfire 在玩家之間建立一個加密的虛擬網路，遊戲資料在其中傳輸。連線分為兩種：

| 方式 | 資料路徑 | 特點 |
| --- | --- | --- |
| **直連** | 玩家之間點對點傳輸 | 延遲最低，接近本地網路 |
| **中轉** | 經由中轉節點轉發 | 適用於雙方網路限制均較嚴的情況，延遲有所增加 |

Campfire 始終優先嚐試直連。能否直連主要取決於雙方的網路型別：多人連線頁面會顯示本機的 NAT 型別（公網、NAT1 至 NAT4）以及是否具備 IPv6。雙方都具備 IPv6 時，幾乎總能建立直連；雙方同為 NAT4 時，通常只能經由中轉。

**連線節點**僅用於幫助玩家互相發現，遊戲資料不會經過 Campfire 的伺服器。只有在允許中轉且直連失敗時，遊戲資料才會經中轉節點傳輸。

連線期間各方能看到哪些資訊、為什麼連線元件無法訪問你電腦上的其他服務，見[連網與安全](./security#多人連線)。連線出現問題時，可先執行[連線診斷](./room#連線診斷)。

## 房間

| 選項 | 說明 |
| --- | --- |
| **玩家名稱** | 在房間中顯示的名稱。留空時使用遊戲中的名稱 |
| **房間顯示名稱** | 加入房間後，多人遊戲列表中顯示的房間名稱 |
| **本地埠** | 加入房間時，本機用於連線房主遊戲的埠。通常無需設定，留空即自動選擇 |
| **尋找房主時限** | 加入房間時等待房主響應的最長時間，可選 30、60 或 120 秒 |
| **建立房間後自動複製邀請碼** | 房間就緒後立即將邀請碼寫入剪貼簿 |
| **自動識別剪貼簿中的邀請碼** | 複製邀請碼後，主頁直接提示加入 |
| **建立房間時自動對區域網開放** | 建立房間後，進入單人世界時由 Campfire 代為對區域網開放，見[自動對區域網開放](./multiplayer#自動對區域網開放) |
| **開房前備份存檔** | 開啟房間時把正在遊玩的世界壓縮儲存一份，每個世界保留最近 5 份，超過 2 GB 的世界不備份，見[存檔備份](./room#存檔備份) |

## 模組

| 選項 | 說明 |
| --- | --- |
| **允許玩家同步我的模組** | 房間內的玩家可比對模組，並同步至與你一致。房間開啟後也可在房間頁面隨時開關 |

## 網路

### 直連失敗時允許通過中轉節點連線

開啟後，直連失敗時經由中轉節點繼續連線，會增加延遲。關閉後，直連失敗將無法加入房間。

### 允許同一區域網中的其他裝置通過本機加入房間

開啟後，與你處於同一真實區域網的其他裝置也能在其區域網世界列表中看到房間，並通過本機加入。關閉後，房間僅出現在本機的區域網世界列表中。

## 中轉伺服器

中轉伺服器幫助玩家互相發現，並在直連失敗時轉發資料。設定中列出了全部內建伺服器及其地區、提供者與實測延遲，可逐個啟用或停用；點選 **測試延遲** 可重新測量。個別伺服器限制中轉速度，會在列表中註明。

連線雙方須至少啟用一個相同的伺服器，才能找到彼此。以上伺服器均由社群成員無償提供。

### 自定義節點

可以填寫自己的節點，支援 `tcp`、`udp`、`ws`、`wss`、`quic`、`http`、`https`、`txt` 與 `srv` 地址，多個地址之間以空格分隔，例如：

```
tcp://example.com:11010 wss://example.com:443
```

無效的地址會在儲存時提示，並在連線時被忽略。停用全部內建伺服器後，房間中的所有玩家都必須使用相同的自定義節點才能找到彼此。

## 隱私

### 隱藏我的 IP 地址

開啟後，全部資料都經由中轉節點傳輸，房主與其他玩家無從得知你的 IP 地址，但中轉節點的運營方仍可看到。該選項會顯著增加延遲，而且只接受直連的玩家將無法與你連線，因此開啟前 Campfire 會再次確認。

### 讀取遊戲中的玩家名稱與賬號型別

僅讀取執行中游戲的玩家名稱、UUID 與賬號型別，用於顯示名稱與識別正版玩家。不讀取、不儲存任何登入憑據。

### 顯示正版玩家的皮膚頭像

開啟後，你的正版賬號 UUID 會共享給房間內的其他玩家，雙方通過 Mojang 官方服務獲取皮膚並生成頭像。

### 向其他玩家顯示軟體版本

關閉後，其他玩家只能看到你在使用 Campfire，看不到具體版本。

### 重置裝置標識

每臺電腦在連線網路中有一個隨機生成的裝置標識。重置後，其他玩家會把這臺電腦視為一臺新裝置。需要在沒有開啟房間時進行。

## 黑名單

列出被你拉黑的玩家與拉黑時間，可逐個解除。被拉黑的玩家無法加入你建立的房間，見[移出與拉黑](./room#移出與拉黑)。

## 資料

| 操作 | 說明 |
| --- | --- |
| **開啟資料資料夾** | 開啟 `%LocalAppData%\Campfire`，其中包含設定、連線日誌與黑名單 |
| **開啟備份資料夾** | 開啟 `%LocalAppData%\Campfire\backups\worlds`，其中儲存著開房前的存檔備份 |
| **清除頭像快取** | 刪除本地快取的皮膚頭像，下次顯示時重新獲取 |
| **刪除連線元件** | 刪除已下載的連線元件，下次連線時重新下載並校驗 |

刪除連線元件需要在沒有開啟房間時進行。
