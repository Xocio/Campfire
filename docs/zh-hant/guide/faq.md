# 常見問題

## 多人連線

### 需要使用特定的啟動器嗎？

不需要。Campfire 直接作用於正在執行的遊戲，無論以何種啟動器、何種賬號型別啟動遊戲，都可以建立或加入房間。採用相同連線協議的其他客戶端，也能與 Campfire 使用者進入同一房間。

### 遊戲資料會經過誰的伺服器？

遊戲資料不經過 Campfire 的伺服器。玩家之間優先點對點直連，連線節點只負責幫助雙方互相發現；只有在允許中轉且直連失敗時，資料才會經中轉節點傳輸。

### 加入時提示「無效會話」

房主以正版賬號開放區域網時，遊戲會校驗每位加入者的身份。請從多人遊戲列表底部的區域網世界中進入房間，而不要通過「直接連線」輸入地址。若仍然出現此提示，可請房主改用離線賬號開放區域網。

### 未找到房間，或一直在尋找房主

可先執行[連線診斷](./room#連線診斷)，它會逐項檢查系統、連線元件、網路、中轉伺服器與本地埠。隨後請依次檢查：

1. 邀請碼是否完整、正確；
2. 房主的房間是否仍處於開啟狀態；
3. 雙方是否至少啟用了一個相同的中轉伺服器。若任何一方停用了全部內建伺服器，雙方必須填寫相同的自定義節點；
4. 若房主使用其他客戶端，雙方同樣需要能連線到相同的節點。

### 提示「房間人數已滿」

房主在房間設定中設定了人數上限，房間內的玩家已達到上限。可稍後重試，或聯絡房主調整，見[房間設定](./room#房間設定)。

### 進入世界時提示缺少模組或模組版本不一致

房主開啟模組同步後，可在多人連線頁面的 **工具 › 模組同步** 中一鍵將本機模組調整為與房主一致，見[模組同步](./mods)。

### 無法開啟或使用語音

- 語音需要模組載入器，原版遊戲無法使用，請改用 Fabric、Forge、NeoForge 或 Quilt 版本。
- 房主安裝語音模組後，須重新啟動遊戲並進入同一個世界，語音才會生效。
- 玩家須擁有與房主遊戲版本及載入器相同的本機版本，併為其安裝語音模組。
- 提示本機 UDP 埠已被佔用時，請關閉佔用該埠的程式後重試。

詳見[語音聊天](./voice)。

### 存檔出了問題，能恢復嗎？

開啟 **開房前備份存檔**（預設開啟）時，每次建立房間都會備份正在遊玩的世界。可在 **工具 › 存檔備份** 中將任一備份還原為新世界，見[存檔備份](./room#存檔備份)。

### 找到了房主，但無法建立直連

多見於雙方網路限制均較嚴的情況，例如同為 NAT4。可以在連線設定中開啟 **直連失敗時允許通過中轉節點連線**，或由網路條件更好的一方擔任房主。雙方都具備 IPv6 時，直連成功率最高。

### 房主看不到我，或連線後沒有響應

若你開啟了 **隱藏我的 IP 地址**，所有資料都必須經由中轉節點傳輸，房主也需要允許中轉連線。此外，房主可能已關閉房間，或網路暫時不穩定，請稍後重試。

### 遊戲內未顯示歡迎訊息與 Tab 資訊，或未自動對區域網開放

這些功能依賴附加到房主遊戲中的元件，支援 1.7.2 及以上的原版與沿用官方名稱的載入器。若房主所用的 Java 執行時不提供附加功能，或遊戲環境經 Fabric、Quilt 等載入器重對映，則需手動對區域網開放，房間資訊亦將退回僅在區域網列表中顯示，遊戲連線不受影響。具體原因記錄在房主電腦的 `%LocalAppData%\Campfire\agent.log` 中。

### 房間未出現在連線大廳中

請確認已在多人連線頁面點選 **公開到連線大廳**，且左下角顯示 **已公開到連線大廳**。房間名稱含有不宜公開的內容、房間遭多名玩家舉報，或同一網路中公開的房間過多時，均無法公開，頁面會說明具體原因，見[公開時的提示](./lobby#公開時的提示)。

### 連線元件下載失敗

請檢查網路連線。若正在使用代理或加速器，可以嘗試將其關閉後重試。

### 提示缺少 Windows 7 更新

在 Windows 7 上使用多人連線，需要通過 Windows 更新安裝 KB3063858 與 KB4474419 並重新啟動。無法使用 Windows 更新時，可以在 Microsoft Update 目錄中按編號手動下載。

### 如何檢視詳細的失敗原因？

可先執行[連線診斷](./room#連線診斷)。失敗頁面還提供 **檢視連線日誌** 按鈕。日誌儲存在 `%LocalAppData%\Campfire\Link\link.log`，反饋問題時請一併附上。

## 地圖

### 匯入的地圖未出現在遊戲中

請確認所啟動的正是匯入時選擇的版本。啟用版本隔離的啟動器會將存檔儲存在版本資料夾中；遊戲啟動後，Campfire 依據執行中的遊戲確認存檔位置，如有不同，將自動遷移地圖。如仍未出現，可在匯入頁面點選 **開啟存檔資料夾** 檢視地圖所在位置。

### 匯入時未列出所需的遊戲版本

Campfire 會查詢預設的 `.minecraft` 資料夾、啟動器旁的 `.minecraft` 資料夾，以及啟動器設定中記錄的遊戲資料夾。遊戲位於其他位置時，請點選 **新增遊戲資料夾**。

### 開啟地圖後命令方塊或紅石失效

將 1.13 之前的地圖匯入 1.13 及以後的版本時，遊戲會轉換地圖格式，命令與紅石常因此失效。請優先選擇標註為 **與地圖版本相同** 的版本。

## 啟動器修復

### 修復安全嗎？

Campfire 只修改與下載、安裝直接相關的少數方法，不新增任何連網行為。修復結果先在記憶體中生成並逐項校驗，通過後才寫入磁碟；任一步驟失敗，原檔案都保持不變。原檔案始終以 `.bak` 備份。詳見[工作原理](./how-it-works#啟動器修復)。

### 提示「暫不支援修復」

說明該啟動器的程式碼結構與已知版本不同，Campfire 無法確認修改位置。此時不會做任何修改。可以在 [GitHub Issues](https://github.com/Xocio/Campfire/issues) 中反饋啟動器的版本。

### 寫入檔案失敗

啟動器可能仍在執行，或位於 `Program Files` 等受保護的資料夾。請關閉啟動器後重試；仍然失敗時，以管理員身份執行 Campfire。

### 修復後啟動器還能更新嗎？

修復會停用啟動器的自動更新，以免更新後功能再次被關閉。需要升級時，請手動下載新版啟動器，再執行 Campfire 檢測是否需要修復。

### 如何撤銷修復？

在啟動器修復工具中點選 **還原**；或刪除修復後的啟動器，再將 `.bak` 檔案改回原名。

## 其他

### Campfire 是否可能被遠端控制？

不會。Campfire 自伺服器接收的僅為文字與列表資料，無法更改設定、執行命令或啟動程式；只有通過簽名校驗的更新與雜湊一致的連線元件才會被執行。全部連網行為與風險邊界見[連網與安全](./security)。

### 防毒軟體報毒

修改其他程式檔案的工具偶爾會被誤判。Campfire 完全開源，可以審閱原始碼並[自行構建](https://github.com/Xocio/Campfire#從原始碼構建)。官方釋出的檔案可以通過[下載頁](/zh-hant/download)中的 SHA-256 核對。

### 關閉視窗後 Campfire 去哪了？

若開啟了 **關閉視窗時保留在通知區域**，Campfire 會繼續在通知區域中執行，房間保持開啟。單擊圖示即可返回視窗。Windows 11 可能將圖示收進工作列右側的 **^** 溢位選單中。

### 再次開啟程式時沒有出現新視窗

同一使用者會話中只執行一個 Campfire。再次開啟時，已在執行的視窗會被切換到前臺；若它隱藏在通知區域中，也會被重新顯示。

### 如何反饋問題？

請在 [GitHub Issues](https://github.com/Xocio/Campfire/issues) 中提交，並儘量附上系統版本、操作步驟，以及連線日誌或截圖。

也可以加入 [Telegram 群聊](https://t.me/CampfireGroup) 交流，或關注 [Telegram 頻道](https://t.me/McCampfire) 獲取更新動態。
