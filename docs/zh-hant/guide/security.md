# 連網與安全

本頁逐項說明 Campfire 的連網行為：連線的物件、發生的時機、傳輸的內容、能否關閉，以及每一項為何不會危及你的電腦與賬號。文中的每一條陳述均可在原始碼中核對，對應位置見[自行核對](#自行核對)。

## 設計原則

以下原則由程式碼保證，並作為長期不變的設計約束：

1. **遠端內容無法控制本機。** Campfire 自伺服器接收的僅為文字、版本號與列表資料，例如公告、更新說明與連線大廳的房間列表。這些內容無法更改任何設定，無法執行命令，無法指定本機路徑，亦無法啟動任何程式。
2. **Campfire 自身僅下載並執行兩類程式，且均經校驗。**
   - **Campfire 自身的更新**：須帶有 Campfire 釋出金鑰的數字簽名，且檔案的實際版本須與宣告一致，否則不予安裝。
   - **連線元件**：每個檔案的 SHA-256 均固定於程式之中，任何一個位元組的差異都會導致其被丟棄。

   模組同步會將模組檔案寫入所選版本的模組資料夾。這些檔案由遊戲載入，Campfire 本身不執行它們，且僅在你確認後寫入，詳見[模組同步](#模組同步)。
3. **無需管理員許可權。** Campfire 以普通許可權執行，不安裝驅動，不建立虛擬網絡卡，不寫入系統目錄。
4. **不觸及賬號。** Campfire 不讀取、不儲存、不上傳任何登入憑據。
5. **啟動器修復完全離線。** 修復僅在本機修改檔案，不連網，也不為啟動器新增任何連網行為。
6. **原始碼構建不連線 Campfire 服務。** 服務地址僅在正式版構建時寫入。自行構建的版本不具備更新檢查、公告、使用統計、連線大廳、線上地圖與 CurseForge 模組查詢，邀請碼連線不受影響。

## Campfire 服務

正式版連線 `https://api.mccampfire.top`，該服務由 Cloudflare 提供服務與安全防護。所有請求均經 HTTPS 加密，並以 `Campfire/版本號` 作為客戶端標識。

### 更新與公告

- **傳送**：不傳送任何內容，也不攜帶任何裝置標識，所有使用者獲得的內容完全相同。
- **接收**：最新版本號、更新說明、下載地址與簽名地址、公告文字，以及檢查間隔。
- **約束**：
  - 公告僅能呈現文字。公告按鈕只能開啟 `https://` 網頁，且僅在使用者點選時開啟，不能啟動程式。
  - 檢查間隔被限定在 1 小時至 7 天之間。
  - 伺服器無法藉此更改任何設定。

### 更新

1. 下載新版本及其簽名後，Campfire 以程式內建的公鑰校驗簽名，並核對檔案的實際版本號，以防舊版本被冒充為新版本。
2. 校驗通過後，Campfire 徵得同意，再替換程式檔案並重新啟動。
3. 未通過校驗的檔案將被直接丟棄。

因此，即便伺服器或下載映象為他人所控制，也無法令 Campfire 安裝經過篡改的程式。

::: info 關於必須更新
當舊版本存在嚴重問題時，伺服器可將新版本標記為必須更新。只有在簽名正確的新版本**確已下載並通過校驗**後，Campfire 才會要求更新後再繼續使用。若下載或校驗失敗，Campfire 照常可用，任何伺服器訊息都無法阻止它啟動。
:::

### 使用統計

僅在授權後傳送，每日至多一次，內容僅限：

- 隨機生成的統計標識，與連線所用的裝置標識無關，可隨時重置；
- 軟體版本、Windows 版本與系統位數、.NET Framework 版本及介面語言；
- 各項功能的使用次數，例如建立房間與加入房間。

統計不包含 IP 地址、遊戲賬號與 UUID、玩家名稱、房間與邀請碼、檔案路徑、硬體序列號及網絡卡地址。伺服器依據網路來源推斷大致的國家與省份，不儲存 IP 地址。下一次傳送的完整內容可在 **設定 › 常規 › 檢視傳送內容** 中檢視。詳見[更新與隱私](./updates-privacy#使用統計)。

### 連線大廳

- **瀏覽**：僅獲取房間列表，不傳送任何內容。
- **公開房間**：傳送房間名稱、標籤、房主名稱、遊戲版本、世界名稱、人數、是否提供語音、邀請碼、可選的房間密碼與圖示，以及一個大廳專用的隨機編號。該編號與裝置標識、統計標識均無關聯。房間開啟期間每隔數分鐘更新一次人數，房間關閉時隨即撤下。
- **加入**：向伺服器領取該房間的邀請碼；設有密碼的房間會一併提交所輸入的密碼。
- **舉報**：僅傳送房間編號與舉報原因。

伺服器僅儲存房間密碼的摘要，不儲存原文；IP 地址僅以加鹽摘要的形式儲存，用於限制釋出頻率與處理違規。大致省份可選擇不予顯示。取消公開或關閉房間後，房間即刻自大廳移除，相關記錄於一天內刪除。

大廳中的房間由其他玩家公開。加入陌生玩家的房間，與加入任何陌生的 Minecraft 伺服器無異。

### 線上地圖

- 瀏覽與搜尋時，Campfire 服務代為查詢 CurseForge 的地圖目錄，僅傳送搜尋詞與篩選條件。
- 地圖檔案與預覽圖僅從 CurseForge 的檔案伺服器 `forgecdn.net` 下載，其餘地址一概拒絕，下載完成後以 SHA-1 校驗。
- 地圖屬於存檔資料而非程式。匯入時僅解壓至所選的存檔資料夾，任何試圖寫入該資料夾之外的檔案都會被拒絕。

## 多人連線

### 連線元件

多人連線以開源網路元件 EasyTier 2.6.4 為基礎。首次連線時，Campfire 依次探測以下地址，並選擇最快者下載：

- `gitee.com`、`github.com`：官方釋出頁；
- `ghfast.top`、`gh-proxy.com`：GitHub 下載加速服務。

三個檔案的 SHA-256 均寫定於 Campfire 的程式碼之中，與官方釋出完全一致。無論來自哪一地址，內容不符的檔案既不會被儲存，也不會被執行。加速服務僅能獲知你的 IP 地址以及你正在下載該元件。

連線元件以普通許可權執行，不安裝虛擬網絡卡，也不為其他網路轉發流量。房主僅向房間開放遊戲與房間服務所需的埠；開啟語音後，另開放房主遊戲中語音服務所用的一個 UDP 埠。加入者不開放任何埠，房間內的玩家無法藉此訪問你電腦上的其他服務。

### 節點與連線

- **連線節點**用於幫助同一房間的玩家互相發現。內建公共節點為 EasyTier 社群節點 `225284.xyz`、`easytier.weiai.org.cn`、`et.basd1.de`、`et.sumnight.top`、`et.chinokou.cn`、`et-public.lctn.top`、`et.南梁.com`、`etnode.zkitefly.eu.org`，以及一個以 IP 地址接入的重慶移動節點。各節點可在 連線設定 › 中轉伺服器 中逐一啟用或停用，亦可僅使用自行填寫的節點。
- **測速**：Campfire 以一個名稱隨機、不接受任何連線的臨時網路逐一連線內建節點，以測得往返延遲，測完即斷開。測速不傳輸任何遊戲資料，節點運營方僅能獲知你的 IP 地址與連線時間。標題欄的指示燈據此顯示節點狀態。
- Campfire 優先在玩家之間建立直連。為此，連線元件可能向公共 STUN 服務探測網路型別，並可能通過 UPnP 在路由器上建立臨時的埠對映。
- 僅在允許中轉且直連失敗時，遊戲資料才會經中轉節點傳輸。
- 遊戲資料在玩家之間加密傳輸，節點無法讀取。節點運營方可獲知你的 IP 地址與連線時間。
- 開啟 **隱藏我的 IP 地址** 後，全部資料均經中轉節點傳輸，其他玩家無從得知你的 IP 地址，但中轉節點的運營方仍可獲知。

相關選項見[網路與隱私](./network)。

### 房間內共享的資訊

房間內的其他玩家可以看到你的玩家名稱、裝置標識，以及你是否使用正版賬號；在開啟相應選項時，還可看到你的正版 UUID 與 Campfire 版本。裝置標識為隨機生成，可隨時重置。

作為房主時，若開啟模組同步，房間內的玩家還可看到你的遊戲版本、模組載入器，以及模組資料夾中各模組的檔名、名稱、版本、SHA-1 與 CurseForge 指紋。模組同步可在連線設定中以 **允許玩家同步我的模組** 設定，亦可在房間頁面隨時開啟或關閉，關閉後立即生效。

### 皮膚頭像

開啟 **顯示正版玩家的皮膚頭像** 後，Campfire 以玩家的 UUID 向 `sessionserver.mojang.com` 查詢皮膚，並從 `textures.minecraft.net` 下載皮膚圖片。關閉後不再查詢。

### 遊戲內元件

Campfire 會將一個小型 Java 元件附加到**房主本機**正在執行的遊戲，用於自動對區域網開放、呈現歡迎訊息與 Tab 資訊。該元件不連網，不啟動程式，也不載入任何外部程式碼。

1.14.4 至 1.21.11 的遊戲需要 Mojang 官方的名稱對映表。對映表自 `piston-data.mojang.com` 下載，無法連線時改由國內映象 `bmclapi2.bangbang93.com` 提供，並以遊戲自帶版本檔案中的 SHA-1 校驗。對映表僅為名稱對照文本，並非程式。

### 模組同步

加入房間後，Campfire 向房主請求其模組列表，並與本機所選版本比對。比對僅讀取本機檔案，不連網。開始同步後：

- **官方源**：先以房主列出的 SHA-1 向 `api.modrinth.com` 查詢，Modrinth 未收錄的再將房主列出的 CurseForge 指紋傳送至 Campfire 服務，由其代為查詢 CurseForge。僅接受 `cdn.modrinth.com` 與 `forgecdn.net` 的 HTTPS 下載地址，且只採用與房主完全相同的檔案。兩項查詢均僅傳送檔案雜湊或指紋。
- **房主**：官方源未收錄或作者不允許第三方下載的檔案，可經連線網路自房主處獲取。獲取前 Campfire 會告知檔案數量並徵得同意。房主僅能按列表中的 SHA-1 提供檔案，玩家無法藉此讀取房主模組資料夾以外的任何檔案；房主可在連線設定中關閉 **允許玩家從我這裡下載模組**。
- **校驗**：無論來自哪一來源，檔案的大小與 SHA-1 均須與房主所列一致，否則即被丟棄。全部檔案下載並校驗完畢後，才會改動模組資料夾。
- **寫入範圍**：僅寫入所選版本的模組資料夾，檔名不得包含路徑。被替換或移除的模組移至 Campfire 資料目錄中的備份資料夾，不會被刪除。下載的檔案快取 14 天。

模組是隨遊戲執行的程式。自房主處獲取模組，與接受房主傳送的整合包無異，請僅在信任房主時使用。

### 語音

語音由開源模組 Simple Voice Chat 提供，Campfire 負責安裝該模組並使其語音資料經連線網路傳輸。

- **房主開啟語音**：若房主遊戲的模組資料夾中沒有該模組，Campfire 向 `api.modrinth.com` 查詢適用於該遊戲版本與模組載入器的最新正式版，僅自 `cdn.modrinth.com` 下載並以 SHA-1 校驗；已停用的同一模組會被重新啟用。若該模組的客戶端設定關閉了單人與區域網世界中的語音，Campfire 會將其重新開啟。新裝的模組在遊戲重新啟動後生效。
- **埠**：僅當房主遊戲的語音服務正在執行時，房主才向房間開放其所用的 UDP 埠。該埠取自遊戲日誌，並核對確由該遊戲佔用；關閉語音後立即撤銷。
- **玩家安裝模組**：玩家點選 **安裝語音模組** 並確認後，Campfire 優先下載與房主完全相同的檔案，Modrinth 未收錄時改為適用於該遊戲版本的最新正式版。檔案僅寫入與房主遊戲版本及載入器相同的本機版本的模組資料夾。
- **語音資料**：語音資料由模組在玩家與房主之間傳輸，並經連線網路加密，Campfire 不讀取、不儲存任何語音內容。

## Android 版

Android 版遵循上述設計原則，以 `Campfire-Android/版本號` 作為用戶端標識。它的連網行為如下，除此之外不存在其他連網行為：

| 功能 | 連線對象 | 時機 | 能否關閉 |
| --- | --- | --- | --- |
| 公告 | Campfire 服務 | 啟動時，此後每隔 6 小時 | 可在設定中關閉 **接收公告** |
| 檢查更新 | Campfire 服務 | 啟動時，或在設定中點擊 **檢測更新** 時 | 預設關閉 |
| 連線大廳 | Campfire 服務 | 瀏覽大廳、加入或檢舉房間時，以及房間公開至大廳期間 | 不使用即不連線；房間關閉後自動從大廳移除 |
| 使用統計 | Campfire 服務 | 授權後每天至多一次 | 預設不傳送，授權後可隨時在應用設定中關閉 |
| 皮膚頭像 | Mojang 官方服務 | 房間內有正版玩家時 | 可在 設定 › 隱私 中關閉 |
| 多人連線 | 連線節點與房間內的其他玩家 | 房間開啟期間 | 節點與中轉均可設定 |
| 節點測速 | 內建連線節點 | 開啟自動選擇節點時於啟動後進行；開啟節點頁面、點擊測試或執行連線診斷時 | 關閉自動選擇節點後，啟動時不再進行 |
| 語音 | Modrinth | 房主開啟語音並安裝語音模組時 | 預設關閉 |
| 開啟網頁 | 系統瀏覽器 | 僅在點擊連結或按鈕時 | — |

- **更新**： Android 版只讀取版本號、更新說明與下載位址。點擊下載後由系統瀏覽器開啟 HTTPS 下載位址，應用自身不下載、不安裝任何程式。
- **連線元件**：隨安裝包一同提供，不另行下載。兩個原生庫的 SHA-256 記錄於 `src/android/easytier/prebuilt.txt`，構建時逐一校驗。
- **語音模組**：僅自 `cdn.modrinth.com` 的 HTTPS 位址下載，SHA-1 須與 Modrinth 所列一致，隨後寫入你所授權的遊戲資料夾中的模組資料夾。
- **遊戲資料夾**：僅在你透過系統檔案選擇器授權後讀寫，範圍限於所授權的資料夾。
- **使用統計**：內容為隨機統計標識（與連線及大廳使用的標識無關）、應用程式版本、 Android 版本、處理器架構、介面語言與功能使用次數（啟動、建立房間、加入房間、公開到大廳、從大廳加入）。大致地區由伺服器依據網路來源推斷，不留存 IP 地址。在 應用設定 › 隱私 中可檢視下一次傳送的完整內容，或重置統計標識。
- **公開到大廳**：傳送房間名稱、介紹、標籤、房主名稱、人數、遊戲版本、世界名稱、是否提供語音與邀請碼。邀請碼只在其他玩家點擊加入時由服務發放；設定了密碼時，服務僅保存密碼的雜湊值。
- **皮膚頭像**：僅以正版玩家的 UUID 向 `sessionserver.mojang.com` 查詢，皮膚僅自 `textures.minecraft.net` 下載，在本機快取一天。
- **不具備的功能**： Android 版沒有線上地圖、模組同步與遊戲內元件，不傳送也不下載相應內容。
- **原始碼構建**：未傳入服務位址的構建不連線 Campfire 服務，公告、更新檢查、使用統計與連線大廳均不出現，邀請碼連線不受影響。

## 風險邊界

即便某一方為他人所控制，其影響亦有明確的邊界：

| 受控的一方 | 影響範圍 | 無法做到 |
| --- | --- | --- |
| Campfire 服務 | 顯示不實的公告文字與網頁連結；篡改大廳列表與地圖目錄；提示一個無法安裝的「更新」 | 安裝或執行任何程式；更改你的設定；讀取你的檔案 |
| 下載映象或加速服務 | 致使下載失敗 | 替換更新或連線元件，簽名與雜湊校驗會將其拒絕 |
| 連線節點或中轉節點 | 獲知你的 IP 地址與連線時間；致使連線失敗 | 讀取遊戲資料；訪問房主遊戲以外的埠 |
| 房間內的其他玩家 | 與常規 Minecraft 連線相同的遊戲內互動 | 訪問你電腦上的其他服務與檔案 |
| 房主（模組同步） | 提供含惡意程式碼的模組，經你確認後由遊戲執行 | 未經你確認寫入檔案；寫入模組資料夾以外的位置；讀取你的檔案 |

## 隱私選項

- **僅使用啟動器修復**：修復功能本身不連網；亦可在 **設定 › 常規** 中關閉 **啟動時檢查更新與公告**。
- **不傳送使用統計**：在首次詢問時拒絕，或在 **設定 › 常規** 中關閉 **傳送匿名使用統計**。
- **連線時保護隱私**：在連線設定中開啟 **隱藏我的 IP 地址**，關閉 **顯示正版玩家的皮膚頭像** 與 **向其他玩家顯示軟體版本**，作為房主時關閉 **允許玩家同步我的模組**，或僅使用自建節點。
- **完全不連線 Campfire 服務**：[從原始碼構建](https://github.com/Xocio/Campfire#從原始碼構建)。
