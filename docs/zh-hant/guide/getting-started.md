# 安裝與上手

## 準備

### 系統要求

- Windows 7 SP1、8、8.1、10 或 11。
- .NET Framework 4.8。Windows 10 與 11 已內建；Windows 7 與 8 如未安裝，請從[微軟官方網站](https://dotnet.microsoft.com/download/dotnet-framework/net48)下載。
- 在 Windows 7 上使用多人連線，還需通過 Windows 更新安裝 **KB3063858** 與 **KB4474419** 並重新啟動。無法使用 Windows 更新時，可在 Microsoft Update 目錄中按編號手動下載。

### 下載

前往[下載頁](/zh-hant/download)獲取最新版本。中國大陸使用者建議使用國內直鏈；也可以從 [GitHub Releases](https://github.com/Xocio/Campfire/releases/latest) 下載。

在手機或平板上遊玩 Minecraft Java 版時，請使用[Android 版](./android)。

## 首次執行

1. 將 `Campfire.exe` 放到任意資料夾並雙擊執行。若需使用啟動器修復，建議將其放在啟動器所在的資料夾中，Campfire 會自動識別。
2. 首次啟動時會出現新手引導，用約半分鐘介紹主頁、地圖、工具與設定。可隨時跳過，之後在 **設定 › 關於** 中再次檢視。
3. 正式版會詢問是否傳送匿名使用統計。該選項完全自願，拒絕不影響任何功能，詳見[更新與隱私](./updates-privacy)。

::: tip 單例項執行
同一 Windows 使用者會話中只會執行一個 Campfire。再次開啟程式時，已在執行的視窗會被切換到前臺，房間不受影響。
:::

## 第一次連線

以下為最簡流程，完整說明見[建立與加入房間](./multiplayer)。

**房主**

1. 在 **主頁** 點選 **建立房間**。
2. 啟動遊戲並進入單人世界，Campfire 會自動將其對區域網開放。
3. 房間隨即建立，邀請碼複製到剪貼簿，傳送給好友即可；亦可將房間公開至[連線大廳](./lobby)。

**好友**

1. 複製房主發來的邀請碼後開啟 Campfire，主頁將提示是否加入該房間；亦可在 **主頁** 點選 **加入房間** 並貼上，或在 **連線大廳** 中選擇房間。
2. 連線完成後，在遊戲的 **多人遊戲** 列表底部找到房間條目，雙擊進入。

::: warning 首次連線需下載連線元件
第一次建立或加入房間時，Campfire 會下載約 14 MB 的連線元件，並逐個檔案校驗完整性。Windows 防火牆可能詢問是否允許其訪問網路，選擇 **允許** 有助於建立直連。
:::

## 第一次修復啟動器

1. 關閉啟動器。
2. 開啟 Campfire，在 **工具** 中選擇 **啟動器修復工具**。Campfire 會自動查詢同一資料夾中的啟動器，也可以點選 **選擇檔案** 或直接將啟動器拖入視窗。
3. 檢視 **修復內容** 中各項的狀態，確認後點擊 **一鍵修復**。

修復完成後即可正常啟動。原檔案以 `.bak` 為字尾備份在同一資料夾中，隨時可通過 **還原** 恢復。詳見[啟動器修復](./launcher-repair)。

## 資料位置

Campfire 的設定、連線元件、日誌與快取預設儲存在 `%LocalAppData%\Campfire`。首次啟動時可以選擇其他位置，之後也可以在 **設定 › 常規 › 儲存位置** 中更改，已有資料會自動轉移。更改後預設資料夾中只保留一個記錄位置的小檔案，下文的路徑相應變為所選資料夾。程式檔案本身可以隨意移動或替換，不會影響已儲存的設定。

| 路徑 | 內容 |
| --- | --- |
| `settings.ini` | 全部設定 |
| `EasyTier\` | 連線元件 |
| `Link\link.log` | 連線日誌，用於排查問題 |
| `Link\blocked.json` | 房主的黑名單 |
| `Link\heads\` | 正版玩家皮膚頭像快取，保留一天 |
| `Link\rooms.txt` | 最近房間與常用房間的記錄 |
| `backups\worlds\` | 開房前的存檔備份，每個世界保留最近 5 份 |
| `backups\mods\` | 模組同步時被替換或移除的模組 |
| `downloads\mods\` | 模組同步下載的檔案，快取 14 天 |
| `agent.log` | 遊戲內元件的日誌 |
| `mappings\` | 遊戲內元件使用的 Mojang 名稱對映表 |
| `downloads\maps\` | 下載的地圖檔案，一週未使用後自動刪除 |

在 **連線設定 › 資料** 中可以直接開啟該資料夾或備份資料夾，或刪除連線元件以便下次重新下載。
