# 模組同步

加入房間後，模組同步會比對本機與房主的遊戲版本和模組，列出不一致之處，並一鍵將本機的模組調整為與房主相同。

## 房主：提供模組列表

模組同步預設開啟。房間開啟後，可在多人連線頁面的 **工具 › 模組同步** 中隨時 **開啟** 或 **關閉**；關閉後立即停止提供模組列表與檔案。也可在 **設定 › 連線 › 模組** 中設定：

| 選項 | 說明 |
| --- | --- |
| **允許玩家同步我的模組** | 房間內的玩家可檢視你的遊戲版本、模組載入器，以及各模組的名稱與版本，並據此同步 |
| **允許玩家從我這裡下載模組** | 官方源未收錄的模組經連線網路自你的電腦傳送，會佔用上傳頻寬。僅模組資料夾中列出的檔案可被下載 |

## 玩家：同步模組

1. 加入房間後，在多人連線頁面的 **工具 › 模組同步** 中點選 **同步**，開啟模組同步頁面。
2. 頁面上方顯示房主的遊戲版本、載入器與模組數量。
3. 在 **本機版本** 中選擇與房主相同的已安裝版本。未列出時，可點選 **新增遊戲資料夾**；仍未找到時，請先在啟動器中安裝該版本。
4. 檢視差異列表：

   | 標記 | 含義 |
   | --- | --- |
   | **缺少** | 房主安裝了，本機沒有 |
   | **版本不同** | 雙方都有，版本不一致 |
   | **房主未安裝** | 本機有，房主沒有。勾選 **移除房主未安裝的模組** 後將其移入備份資料夾 |

   小地圖、光影等僅需一方安裝的模組不計入差異。

5. 選擇 **下載來源**，點選 **同步模組**。

| 下載來源 | 說明 |
| --- | --- |
| **優先官方源** | 自 Modrinth 與 CurseForge 下載與房主完全相同的檔案，官方源未收錄或不允許第三方下載的再自房主獲取 |
| **僅官方源** | 只從 Modrinth 與 CurseForge 下載，無法獲取的模組會在完成後列出，需自行安裝 |
| **全部從房主獲取** | 全部檔案經連線網路自房主的電腦傳送 |

::: warning 請僅在信任房主時自房主獲取模組
模組是隨遊戲執行的程式。需要自房主獲取檔案時，Campfire 會先告知檔案數量並徵得同意。
:::

## 安全保障

- 無論來自哪一來源，檔案的大小與 SHA-1 均須與房主所列一致，否則即被丟棄。
- 全部檔案下載並校驗完畢後，才會改動模組資料夾。
- 被替換或移除的模組移入備份資料夾，不會被刪除，可在完成後點選 **開啟備份資料夾** 找回。
- 房主只能按列表提供模組資料夾中的檔案，玩家無法藉此讀取房主的其他檔案。

更完整的說明見[連網與安全](./security#模組同步)。

## 常見提示

| 提示 | 處理 |
| --- | --- |
| 房主未開啟模組同步 | 請房主在 **工具 › 模組同步** 中開啟 |
| 未找到與房主相同的遊戲版本 | 先在啟動器中安裝與房主相同的版本，再返回此頁 |
| 該版本的遊戲正在執行 | 關閉遊戲後再同步 |
| 模組資料夾中的檔案正被佔用 | 關閉遊戲後重試 |
| 房主未提供該檔案 | 房主可能已關閉模組下載或更換了模組 |
| 下載的檔案與房主的檔案不符，已丟棄 | 請重試，或改用其他下載來源 |
| 已離開房間，無法再從房主處獲取模組 | 重新加入房間後再同步 |
