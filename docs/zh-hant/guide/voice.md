# 語音聊天

Campfire 藉助開源模組 Simple Voice Chat 為房間提供語音。房主開啟語音後，Campfire 會為遊戲安裝並啟用該模組，語音經連線網路加密傳輸，無需埠對映；房間內安裝同一模組的玩家進入世界後即可相互交談。

## 開始之前

- 語音需要模組載入器：請使用 Fabric、Forge、NeoForge 或 Quilt 版本的遊戲，原版無法使用。
- 玩家須擁有與房主遊戲版本及模組載入器相同的本機版本。
- 語音適用於由房主遊戲開放的區域網世界，專用伺服器暫不支援開啟語音。
- 語音預設關閉，僅在房主開啟後提供。

## 房主：開啟語音

1. 建立房間後，在多人連線頁面的 **工具** 卡片中找到 **語音**，點選 **開啟**。
2. 若遊戲中尚未安裝該模組，Campfire 會從 Modrinth 下載適用於該遊戲版本與載入器的最新正式版，校驗後放入遊戲的模組資料夾；已停用的同一模組會被重新啟用。
3. 新裝的模組需要重新啟動遊戲才會生效。Campfire 會彈出提示，請關閉並重新啟動遊戲，進入同一個世界。

重新啟動遊戲期間，房間保持開啟，邀請碼不變，房間內的玩家無需重新加入。10 分鐘內回到同一個世界，Campfire 會自動對區域網開放並恢復房間；未開啟自動對區域網開放時，請手動開放。

**語音** 一欄會顯示當前狀態：

| 狀態 | 說明 |
| --- | --- |
| 未開啟 | 點選 **開啟** 後為遊戲安裝語音模組 |
| 正在下載語音模組 | 正在自 Modrinth 下載並校驗 |
| 已安裝，重新啟動遊戲並進入世界後生效 | 請重新啟動遊戲，房間會保持開啟 |
| 已開啟 | 遊戲中的語音服務已執行，安裝了語音模組的玩家可相互交談 |

點選 **關閉** 後，Campfire 立即停止轉發語音，房間內玩家的語音隨即中斷。模組仍保留在遊戲中，不再需要時可在啟動器中自行移除。

## 玩家：安裝語音模組

房主開啟語音後，玩家的多人連線頁面會在 **工具 › 語音** 中提示安裝：

1. 點選 **安裝**，確認要安裝的模組與目標版本。
2. Campfire 優先下載與房主完全相同的檔案；Modrinth 未收錄時，改為適用於該遊戲版本的最新正式版。檔案僅寫入與房主遊戲版本及載入器相同的本機版本的模組資料夾。
3. 啟動該版本的遊戲並進入房主的世界即可交談；安裝時遊戲已在執行的，請重新啟動遊戲。

| 狀態 | 說明 |
| --- | --- |
| 房主未開啟語音 | 房主開啟後才能使用 |
| 房主已開啟語音，將在房主重新啟動遊戲後可用 | 房主的遊戲尚未載入語音模組 |
| 房主已開啟語音，為版本 … 安裝語音模組後即可使用 | 點選 **安裝** |
| 未找到與房主遊戲版本及模組載入器相同的版本 | 請先在啟動器中安裝相同的版本 |
| 本機 UDP 埠 … 已被佔用 | 請關閉佔用該埠的程式後重試 |
| 已就緒 | 進入房主的世界後即可語音交流 |

進入世界後，按鍵、麥克風與音量均在模組的設定介面中調整，預設按 **V** 開啟。

## 在連線大廳中

提供語音的房間在連線大廳中帶有 **語音** 標籤，房間詳情中也會註明，加入後在房間頁面安裝語音模組即可使用。

## 隱私

語音資料由模組在玩家與房主之間傳輸，並經連線網路加密。Campfire 不讀取、不儲存任何語音內容。房主僅在語音服務執行時向房間開放其所用的一個 UDP 埠，關閉語音後立即撤銷。詳見[連網與安全](./security#語音)。
