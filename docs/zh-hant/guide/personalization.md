# 個性化

個性化選項位於 **設定 › 個性化**。所有更改即時生效。

## 主題模式

| 模式 | 說明 |
| --- | --- |
| **跟隨系統** | 隨 Windows 的淺色或深色設定自動切換 |
| **淺色** | 始終使用淺色介面 |
| **深色** | 始終使用深色介面 |

## 顏色來源

Campfire 的整套介面配色由一種主題色生成，包括按鈕、強調色、背景與文本的層次。主題色可以來自三處：

### 自選顏色

從預設色板中選取，或輸入形如 `#E2680C` 的六位十六進位制色值後按回車應用。預設的篝火橙即為 `#E2680C`。

### 莫奈取色

自動從桌面桌布中提取最具代表性的顏色，並據此生成整套配色。更換桌布後，配色會隨之更新；也可以點選 **重新取色** 立即重新整理。若桌布的顏色不夠鮮明，Campfire 會改用 Windows 主題色。

### Windows 主題色

沿用 Windows 個性化設定中的主題色。

## 配色風格

同一種主題色可以生成不同性格的配色：

| 風格 | 特點 |
| --- | --- |
| **標準** | 貼近主題色，明暗搭配均衡，適合大多數情況 |
| **鮮豔** | 在螢幕可顯示的範圍內儘量提高飽和度 |
| **多彩** | 在主題色的基礎上偏移色相，呈現更活潑的配色 |
| **柔和** | 以灰色為主，僅保留少量主題色 |
| **單色** | 完全使用灰色，不帶任何色彩 |
| **原色** | 儘量保留主題色本身的色彩與飽和度 |

配色在感知均勻的色彩空間中計算，因此無論選擇何種顏色，文本與背景之間都能保持穩定的對比度。

## 動畫

**啟用介面動畫** 控制頁面切換、彈窗與主題變更時的過渡動效。關閉後，所有介面變化即時完成。

## 語言

Campfire 提供簡體中文與 English 兩種介面語言，首次啟動時跟隨系統語言。可以在 **設定 › 常規 › 語言** 中切換，也可以點選標題欄上的語言按鈕快速切換。

## 通知區域

| 選項 | 說明 |
| --- | --- |
| **在通知區域顯示 Campfire 圖示** | 以圖示呈現連線狀態，房間開啟期間火焰常亮。單擊圖示展開視窗，右鍵檢視房間、複製邀請碼或退出 |
| **關閉視窗時保留在通知區域** | 點選視窗的關閉按鈕僅隱藏視窗，房間保持開啟。需要退出時，請使用通知區域圖示的選單 |

::: tip 圖示沒有出現
Windows 11 預設會將新程式的圖示收進通知區域的溢位選單中。點選工作列右側的 **^** 即可找到；也可以在 Windows 的「工作列設定」中將其設為始終顯示。
:::
