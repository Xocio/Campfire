# JRE 啟用工具

部分啟動器會將不含 `javac.exe` 的 Java，即 JRE，預設標記為停用；Java 9 及以上的 JRE 更是始終無法選擇。這使得僅安裝了 JRE 的電腦無法用其啟動遊戲。JRE 啟用工具可以解除這一限制，使 JRE 與 JDK 一樣預設可用。

該工具獨立於啟動器修復，兩者可以單獨使用，備份也互不影響。

## 使用方法

1. 關閉啟動器。
2. 在 Campfire 的 **工具** 中選擇 **JRE 啟用工具**。
3. Campfire 會自動查詢同一資料夾中的啟動器；也可以點選 **選擇檔案** 或將其拖入視窗。
4. 確認 **處理內容** 中顯示 **待處理** 後，點選 **啟用 JRE**。

處理完成後，新發現或新匯入的 JRE 會預設啟用。

::: warning 已被停用的 JRE 需手動啟用一次
處理之前已被啟動器記錄為「停用」的 JRE，不會自動恢復。請在啟動器的 Java 列表中將其手動啟用一次。
:::

## 處理內容

工具只移除與 JRE 相關的兩項限制：

- 不再因缺少 `javac.exe` 而預設停用 Java；
- 不再禁止選擇 Java 9 及以上的 JRE。

「系統位數必須與 Java 位數一致」的檢查保持不變，以免選中無法執行的 Java。整個改動僅涉及極少量位元組，檔案大小與打包佈局均保持原樣，無需重新打包。

## 檢測結果

| 提示 | 含義 |
| --- | --- |
| 預設停用 JRE，可予以解除 | 可以處理 |
| 已經可以使用 JRE | 此前已處理過 |
| 此版本不存在 JRE 限制 | 無需處理 |
| 所選檔案並非受支援的啟動器 | 該啟動器本身不存在此限制 |
| 程式碼結構與已知版本不同，暫不支援處理 | 無法確認修改位置，不會做任何修改 |

## 備份與還原

處理前的啟動器儲存為同一資料夾中的 `.jre.bak` 檔案，與啟動器修復產生的 `.bak` 相互獨立。點選 **還原** 即可恢復處理前的狀態。
