# 个性化

个性化选项位于 **设置 › 个性化**。所有更改即时生效。

## 主题模式

| 模式 | 说明 |
| --- | --- |
| **跟随系统** | 随 Windows 的浅色或深色设置自动切换 |
| **浅色** | 始终使用浅色界面 |
| **深色** | 始终使用深色界面 |

## 颜色来源

Campfire 的整套界面配色由一种主题色生成，包括按钮、强调色、背景与文本的层次。主题色可以来自三处：

### 自选颜色

从预设色板中选取，或输入形如 `#E2680C` 的六位十六进制色值后按回车应用。默认的篝火橙即为 `#E2680C`。

### 莫奈取色

自动从桌面壁纸中提取最具代表性的颜色，并据此生成整套配色。更换壁纸后，配色会随之更新；也可以点击 **重新取色** 立即刷新。若壁纸的颜色不够鲜明，Campfire 会改用 Windows 主题色。

### Windows 主题色

沿用 Windows 个性化设置中的主题色。

## 配色风格

同一种主题色可以生成不同性格的配色：

| 风格 | 特点 |
| --- | --- |
| **标准** | 贴近主题色，明暗搭配均衡，适合大多数情况 |
| **鲜艳** | 在屏幕可显示的范围内尽量提高饱和度 |
| **多彩** | 在主题色的基础上偏移色相，呈现更活泼的配色 |
| **柔和** | 以灰色为主，仅保留少量主题色 |
| **单色** | 完全使用灰色，不带任何色彩 |
| **原色** | 尽量保留主题色本身的色彩与饱和度 |

配色在感知均匀的色彩空间中计算，因此无论选择何种颜色，文本与背景之间都能保持稳定的对比度。

## 动画

**启用界面动画** 控制页面切换、弹窗与主题变更时的过渡动效。关闭后，所有界面变化即时完成。

## 语言

Campfire 提供简体中文与 English 两种界面语言，首次启动时跟随系统语言。可以在 **设置 › 常规 › 语言** 中切换，也可以点击标题栏上的语言按钮快速切换。

## 通知区域

| 选项 | 说明 |
| --- | --- |
| **在通知区域显示 Campfire 图标** | 以图标呈现联机状态，房间开启期间火焰常亮。单击图标展开窗口，右键查看房间、复制邀请码或退出 |
| **关闭窗口时保留在通知区域** | 点击窗口的关闭按钮仅隐藏窗口，房间保持开启。需要退出时，请使用通知区域图标的菜单 |

::: tip 图标没有出现
Windows 11 默认会将新程序的图标收进通知区域的溢出菜单中。点击任务栏右侧的 **^** 即可找到；也可以在 Windows 的“任务栏设置”中将其设为始终显示。
:::
