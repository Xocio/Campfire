# 网络与隐私

本页介绍联机设置中的各个选项。联机设置位于 **设置 › 联机**，也可从主页的 **联机设置** 磁贴，或点击标题栏的中转服务器指示灯打开。

::: info
设置更改会即时保存，并在下次创建或加入房间时生效。
:::

## 连接方式

Campfire 在玩家之间建立一个加密的虚拟网络，游戏数据在其中传输。连接分为两种：

| 方式 | 数据路径 | 特点 |
| --- | --- | --- |
| **直连** | 玩家之间点对点传输 | 延迟最低，接近本地网络 |
| **中转** | 经由中转节点转发 | 适用于双方网络限制均较严的情况，延迟有所增加 |

Campfire 始终优先尝试直连。能否直连主要取决于双方的网络类型：多人联机页面会显示本机的 NAT 类型（公网、NAT1 至 NAT4）以及是否具备 IPv6。双方都具备 IPv6 时，几乎总能建立直连；双方同为 NAT4 时，通常只能经由中转。

**联机节点**仅用于帮助玩家互相发现，游戏数据不会经过 Campfire 的服务器。只有在允许中转且直连失败时，游戏数据才会经中转节点传输。

联机期间各方能看到哪些信息、为什么联机组件无法访问你电脑上的其他服务，见[联网与安全](./security#多人联机)。连接出现问题时，可先运行[联机诊断](./room#联机诊断)。

## 房间

| 选项 | 说明 |
| --- | --- |
| **玩家名称** | 在房间中显示的名称。留空时使用游戏中的名称 |
| **房间显示名称** | 加入房间后，多人游戏列表中显示的房间名称 |
| **本地端口** | 加入房间时，本机用于连接房主游戏的端口。通常无需设置，留空即自动选择 |
| **寻找房主时限** | 加入房间时等待房主响应的最长时间，可选 30、60 或 120 秒 |
| **创建房间后自动复制邀请码** | 房间就绪后立即将邀请码写入剪贴板 |
| **自动识别剪贴板中的邀请码** | 复制邀请码后，主页直接提示加入 |
| **创建房间时自动对局域网开放** | 创建房间后，进入单人世界时由 Campfire 代为对局域网开放，见[自动对局域网开放](./multiplayer#自动对局域网开放) |
| **开房前备份存档** | 开启房间时把正在游玩的世界压缩保存一份，每个世界保留最近 5 份，超过 2 GB 的世界不备份，见[存档备份](./room#存档备份) |

## 模组

| 选项 | 说明 |
| --- | --- |
| **允许玩家同步我的模组** | 房间内的玩家可比对模组，并同步至与你一致。房间开启后也可在房间页面随时开关 |
| **允许玩家从我这里下载模组** | 官方源未收录的模组经联机网络自你的电脑传送，会占用上传带宽 |

详见[模组同步](./mods)。

## 网络

### 直连失败时允许通过中转节点连接

开启后，直连失败时经由中转节点继续连接，会增加延迟。关闭后，直连失败将无法加入房间。

### 允许同一局域网中的其他设备通过本机加入房间

开启后，与你处于同一真实局域网的其他设备也能在其局域网世界列表中看到房间，并通过本机加入。关闭后，房间仅出现在本机的局域网世界列表中。

## 中转服务器

中转服务器帮助玩家互相发现，并在直连失败时转发数据。设置中列出了全部内置服务器及其地区、提供者与实测延迟，可逐个启用或停用；点击 **测试延迟** 可重新测量。个别服务器限制中转速度，会在列表中注明。

联机双方须至少启用一个相同的服务器，才能找到彼此。以上服务器均由社区成员无偿提供。

### 自定义节点

可以填写自己的节点，支持 `tcp`、`udp`、`ws`、`wss`、`quic`、`http`、`https`、`txt` 与 `srv` 地址，多个地址之间以空格分隔，例如：

```
tcp://example.com:11010 wss://example.com:443
```

无效的地址会在保存时提示，并在联机时被忽略。停用全部内置服务器后，房间中的所有玩家都必须使用相同的自定义节点才能找到彼此。

## 隐私

### 隐藏我的 IP 地址

开启后，全部数据都经由中转节点传输，房主与其他玩家无从得知你的 IP 地址，但中转节点的运营方仍可看到。该选项会显著增加延迟，而且只接受直连的玩家将无法与你连接，因此开启前 Campfire 会再次确认。

### 读取游戏中的玩家名称与账号类型

仅读取运行中游戏的玩家名称、UUID 与账号类型，用于显示名称与识别正版玩家。不读取、不保存任何登录凭据。

### 显示正版玩家的皮肤头像

开启后，你的正版账号 UUID 会共享给房间内的其他玩家，双方通过 Mojang 官方服务获取皮肤并生成头像。

### 向其他玩家显示软件版本

关闭后，其他玩家只能看到你在使用 Campfire，看不到具体版本。

### 重置设备标识

每台电脑在联机网络中有一个随机生成的设备标识。重置后，其他玩家会把这台电脑视为一台新设备。需要在没有开启房间时进行。

## 黑名单

列出被你拉黑的玩家与拉黑时间，可逐个解除。被拉黑的玩家无法加入你创建的房间，见[移出与拉黑](./room#移出与拉黑)。

## 数据

| 操作 | 说明 |
| --- | --- |
| **打开数据文件夹** | 打开 `%LocalAppData%\Campfire`，其中包含设置、联机日志与黑名单 |
| **打开备份文件夹** | 打开 `%LocalAppData%\Campfire\backups\worlds`，其中保存着开房前的存档备份 |
| **清除头像缓存** | 删除本地缓存的皮肤头像，下次显示时重新获取 |
| **删除联机组件** | 删除已下载的联机组件，下次联机时重新下载并校验 |

删除联机组件需要在没有开启房间时进行。
