# 认识 Campfire

Campfire 是一款面向 Minecraft Java 版玩家的 Windows 工具箱。它将远程多人游戏、联机大厅、地图与启动器修复整合于同一程序之中：无需安装，不写入注册表，从 Windows 7 SP1 到 Windows 11 均可运行。

## 设计理念

**专注而轻量。** Campfire 只做少数几件事，并力求把每一件做得足够细致。程序本体不依赖安装器，联机所需的网络组件仅在首次使用时按需下载，并逐个文件校验。

**与启动器无关。** 多人联机直接作用于正在运行的游戏，而非某一款启动器。无论使用何种启动器、何种账号类型启动游戏，均可创建或加入房间。采用相同联机协议的其他客户端，也能与 Campfire 用户进入同一房间。

**透明可验证。** Campfire 的全部源代码公开。对启动器的每一处修改都限定在明确的方法之内，于内存中校验无误后才写入磁盘，并始终保留可还原的备份。远程内容仅限文字与列表数据，无法更改设置或运行程序，全部联网行为见[联网与安全](./security)。

## 主要功能

### 多人联机

房主创建房间并进入单人世界后，Campfire 会自动将其对局域网开放并生成邀请码。好友加入房间后，房主的世界会出现在其游戏的局域网世界列表中，双击即可进入，体验与身处同一局域网无异。

- 优先在玩家之间建立点对点直连，网络条件受限时可经中转节点传输。
- 房间可公开至联机大厅，供更多玩家发现与加入。
- 进入世界后，聊天栏呈现欢迎消息，Tab 列表的页眉与页脚实时显示房主、在线人数与延迟，覆盖 1.7.2 及以上的全部正式版。
- 房主可查看成员、移出或拉黑访客；访客可选择隐藏自己的 IP 地址。

详见[创建与加入房间](./multiplayer)与[联机大厅](./lobby)。

### 地图

- 浏览、检索并下载 CurseForge 上的地图。
- 导入时识别地图的游戏版本，置入本机能够开启它的版本，并提示升级风险；导入后即可创建房间。

详见[地图](./maps)。

### 工具

- **启动器修复**：恢复被启动器停用的游戏下载、加载器安装与整合包安装，并可解除按地区关闭的下载功能。详见[启动器修复](./launcher-repair)。
- **JRE 启用工具**：解除启动器对 JRE 的默认停用，使 JRE 与 JDK 一样可用于启动游戏。详见[JRE 启用工具](./jre)。

### 体验

- 浅色与深色模式，自选主题色、Windows 主题色或由桌面壁纸自动取色，并提供六种配色风格。
- 页面切换、弹窗与控件均配有过渡动效，可随时关闭。
- 通知区域图标实时反映联机状态，关闭窗口后房间仍可在后台保持。
- 简体中文与 English 双语界面，默认跟随系统语言。

Campfire 的窗口分为四个标签页：

| 标签页 | 内容 |
| --- | --- |
| 主页 | 创建房间、加入房间与联机大厅入口，当前房间状态与联机步骤 |
| 地图 | CurseForge 地图浏览与下载，导入本地地图 |
| 工具 | 启动器修复工具、JRE 启用工具；检测到可修复的启动器时，标签旁显示红点 |
| 设置 | 个性化、常规、关于与开源许可 |

首次启动时，Campfire 会通过一段简短的新手引导介绍上述区域；之后可在 **设置 › 关于** 中再次查看。

## 开源与许可

Campfire 是开源免费的社区项目，源代码托管于 [GitHub](https://github.com/Xocio/Campfire)。程序所使用的第三方组件及其许可，可在 **设置 › 开源许可** 中查看。Campfire 与 Mojang Studios 及微软均无关联。
