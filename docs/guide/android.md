# Android 版

Campfire Android 版让在手机或平板上游玩 Minecraft Java 版的玩家也能创建与加入房间。它与桌面版使用同一套联机协议，手机与电脑上的玩家可以进入同一房间，邀请码与联机大厅在两端通用。

## 系统要求

- Android 7.0 及以上版本。
- 64 位 ARM 处理器，近年的手机与平板均满足此条件。
- 一款能够运行 Minecraft Java 版的 Android 启动器。Campfire 作用于正在运行的游戏，不限定启动器。

## 下载与安装

1. 在[下载页](/download#android-版)下载 `Campfire.apk`。中国大陆用户建议使用国内直链。
2. 打开下载的文件。系统询问是否允许安装未知来源应用时，为浏览器或文件管理器开启该权限，再继续安装。
3. 首次打开时，Campfire 会依次检查系统版本、通知、后台运行与局域网访问，并说明每一项的用途。

::: tip 后台运行
游戏在前台运行时，Campfire 需要在后台保持房间连接。请允许 Campfire 在后台运行，并在系统的电池设置中将其设为不受限制。房间开启期间，通知栏会持续显示房间状态，可从通知中复制邀请码或关闭房间。
:::

## 界面概览

| 标签页 | 内容 |
| --- | --- |
| 主页 | 创建房间、加入房间、当前房间状态与联机步骤；卡片可长按拖动排序，也可从主页关闭 |
| 大厅 | 浏览联机大厅中公开的房间 |
| 设置 | 联机设置：玩家、网络、隐私、游戏文件夹、房间与诊断 |

主页右上角的按钮通往 **应用设置**，其中包含主题设置、语言、更新与公告、支持项目与关于。

## 创建房间

1. 在 **主页** 点击 **创建房间**，再点击 **开始**。
2. 回到启动器，进入单人世界，并在游戏菜单中选择 **对局域网开放**。
3. 连接 Wi-Fi 时，Campfire 会自动发现该世界并开启房间；使用移动数据时，请改用 **手动输入端口**，填写游戏聊天栏中显示的端口号。
4. 房间开启后，点击 **复制邀请码** 或 **分享**，将邀请码发送给其他玩家。

::: warning 需要手动对局域网开放
Android 系统不允许一个应用读取或修改另一个应用的运行状态，因此 Android 版无法像桌面版那样自动对局域网开放世界，也不会在游戏聊天栏与 Tab 列表中显示房间信息。退出世界后，房间会自动关闭。
:::

房间页的 **工具** 卡片包含 **房间设置**、**公开到联机大厅**、**白名单**、**语音** 与 **联机诊断**；在玩家列表中可以将玩家移出房间或添加至白名单。房间名称、人数上限与公告的说明见[房间管理](./room)。

## 加入房间

1. 复制房主发来的邀请码后打开 Campfire，应用会询问是否加入该房间；也可以在 **主页** 点击 **加入房间**，粘贴邀请码或整段聊天消息。
2. 连接完成后，打开启动器进入游戏，在 **多人游戏** 列表底部找到 **Campfire 联机房间**，点击进入。

邀请码以 `U/` 开头，共四组字符，与桌面版完全相同。房主使用正版账号时，请从局域网世界条目进入，而非直接连接房间页中显示的地址。

## 联机大厅

**大厅** 标签页列出所有公开的房间，桌面版与 Android 版的房间都会显示在其中。房间带有密码时，点击 **加入房间** 后需要输入密码。认为房间的名称或内容不当时，可在房间详情中举报。

### 公开房间

房主可以在房间页的 **工具** 卡片中打开 **公开到联机大厅**，填写房间介绍与密码，选择至多 3 个标签，再点击 **公开**。房间名称沿用房间设置中的名称，大厅显示其前 24 个字；游戏版本与世界名称由 Campfire 自动读取。公开后，房间的人数与语音状态会随时同步至大厅；房间关闭后自动从大厅移除，也可以随时点击 **取消公开**。

## 语音

房主在房间页开启语音后，Campfire 会为游戏安装语音模组 Simple Voice Chat，并为玩家转发语音数据。语音需要以下准备：

- **授权游戏文件夹**：在 **设置 › 游戏文件夹** 中授权启动器的游戏文件夹。Campfire 能识别常见的 Android 启动器，也可以选择任意启动器的 `.minecraft` 文件夹。Campfire 只读取版本信息，并写入自己安装的模组。
- **使用带模组加载器的版本**：语音模组需要 Fabric、Forge、NeoForge 或 Quilt。
- **重新启动游戏**：安装语音模组后，需重新启动游戏并进入世界，语音方可生效。

完整说明见[语音聊天](./voice)。

## 联机设置

**设置** 标签页即联机设置，包含以下内容：

- **玩家**：玩家名称与游戏内名称。
- **网络**：允许中转、隐藏我的 IP 地址、寻找房主的时限、识别剪贴板中的邀请码，以及 **中转服务器**。中转服务器页面可测速、选择内置服务器或添加自定义节点。
- **隐私**：显示正版玩家的皮肤头像、向其他玩家显示软件版本，以及重置设备标识。
- **游戏**：游戏文件夹。
- **房间**：房间设置与白名单。
- **诊断**：**联机诊断** 逐项检查系统、联机组件、网络连接、中转服务器、本地端口与局域网世界，并给出处理建议；**联机日志** 记录加入与创建房间的过程，可直接分享给他人排查问题。

## 与桌面版的区别

| 功能 | Android 版 |
| --- | --- |
| 邀请码联机、联机大厅、房间设置、白名单、语音、皮肤头像、联机诊断、使用统计 | 支持 |
| 自动对局域网开放世界 | 不支持，需在游戏中手动开放 |
| 游戏内欢迎消息与 Tab 列表信息 | 不支持 |
| 模组同步、在线地图、启动器修复、JRE 启用工具 | 不提供 |
| 联机组件 | 随安装包提供，无需另行下载 |

## 更新与隐私

- **公告**：启动时获取 Campfire 发布的公告，可在 **应用设置** 中关闭 **接收公告**。
- **使用统计**：首次进入主界面时，Campfire 会询问是否发送匿名使用统计，默认不发送。允许后每天最多发送一次，可在 **应用设置** 中关闭、查看下一次发送的内容或重置统计标识。
- **皮肤头像**：房间内有正版玩家时，玩家列表显示其皮肤头像，可在 **设置** 中关闭 **显示正版玩家的皮肤头像**。
- **检测更新**：默认关闭。在 **应用设置** 中开启后，Campfire 会在启动时检查新版本；发现新版本时，点击 **更新** 将在浏览器中打开下载地址，应用本身不会下载或安装任何程序。
- Android 版的全部联网行为见[联网与安全](./security#android-版)。

## 常见问题

### 自动发现不到我的世界

请确认已在游戏中对局域网开放世界，且已在首次启动或系统设置中允许 Campfire 访问局域网。使用移动数据或部分公共 Wi-Fi 时无法自动发现，请改用 **手动输入端口**。

### 玩家进入世界后很快断开

多见于系统在后台限制了 Campfire。请在系统设置中允许 Campfire 后台运行，并关闭对它的电池优化。

### 无法加入房间

请先运行 **联机诊断**。双方网络限制均较严时可能无法直连，可在联机设置中允许中转，或由网络条件更好的一方担任房主。其他问题见[常见问题](./faq)。
