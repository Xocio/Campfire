# JRE 启用工具

部分启动器会将不含 `javac.exe` 的 Java，即 JRE，默认标记为停用；Java 9 及以上的 JRE 更是始终无法选择。这使得仅安装了 JRE 的电脑无法用其启动游戏。JRE 启用工具可以解除这一限制，使 JRE 与 JDK 一样默认可用。

该工具独立于启动器修复，两者可以单独使用，备份也互不影响。

## 使用方法

1. 关闭启动器。
2. 在 Campfire 的 **工具** 中选择 **JRE 启用工具**。
3. Campfire 会自动查找同一文件夹中的启动器；也可以点击 **选择文件** 或将其拖入窗口。
4. 确认 **处理内容** 中显示 **待处理** 后，点击 **启用 JRE**。

处理完成后，新发现或新导入的 JRE 会默认启用。

::: warning 已被停用的 JRE 需手动启用一次
处理之前已被启动器记录为“停用”的 JRE，不会自动恢复。请在启动器的 Java 列表中将其手动启用一次。
:::

## 处理内容

工具只移除与 JRE 相关的两项限制：

- 不再因缺少 `javac.exe` 而默认停用 Java；
- 不再禁止选择 Java 9 及以上的 JRE。

“系统位数必须与 Java 位数一致”的检查保持不变，以免选中无法运行的 Java。整个改动仅涉及极少量字节，文件大小与打包布局均保持原样，无需重新打包。

## 检测结果

| 提示 | 含义 |
| --- | --- |
| 默认停用 JRE，可予以解除 | 可以处理 |
| 已经可以使用 JRE | 此前已处理过 |
| 此版本不存在 JRE 限制 | 无需处理 |
| 所选文件并非受支持的启动器 | 该启动器本身不存在此限制 |
| 代码结构与已知版本不同，暂不支持处理 | 无法确认修改位置，不会做任何修改 |

## 备份与还原

处理前的启动器保存为同一文件夹中的 `.jre.bak` 文件，与启动器修复产生的 `.bak` 相互独立。点击 **还原** 即可恢复处理前的状态。
