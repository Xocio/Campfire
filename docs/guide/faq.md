# 常见问题

## 多人联机

### 需要使用特定的启动器吗？

不需要。Campfire 直接作用于正在运行的游戏，无论以何种启动器、何种账号类型启动游戏，都可以创建或加入房间。采用相同联机协议的其他客户端，也能与 Campfire 用户进入同一房间。

### 游戏数据会经过谁的服务器？

游戏数据不经过 Campfire 的服务器。玩家之间优先点对点直连，联机节点只负责帮助双方互相发现；只有在允许中转且直连失败时，数据才会经中转节点传输。

### 加入时提示“无效会话”

房主以正版账号开放局域网时，游戏会校验每位加入者的身份。请从多人游戏列表底部的局域网世界中进入房间，而不要通过“直接连接”输入地址。若仍然出现此提示，可请房主改用离线账号开放局域网。

### 未找到房间，或一直在寻找房主

请依次检查：

1. 邀请码是否完整、正确；
2. 房主的房间是否仍处于开启状态；
3. 双方是否都能连接到相同的联机节点。若任何一方关闭了内置公共节点，双方必须填写相同的自定义节点；
4. 若房主使用其他客户端，双方同样需要能连接到相同的节点。

### 找到了房主，但无法建立直连

多见于双方网络限制均较严的情况，例如同为 NAT4。可以在联机设置中开启 **直连失败时允许通过中转节点连接**，或由网络条件更好的一方担任房主。双方都具备 IPv6 时，直连成功率最高。

### 房主看不到我，或连接后没有响应

若你开启了 **隐藏我的 IP 地址**，所有数据都必须经由中转节点传输，房主也需要允许中转连接。此外，房主可能已关闭房间，或网络暂时不稳定，请稍后重试。

### 游戏内未显示欢迎消息与 Tab 信息，或未自动对局域网开放

这些功能依赖附加到房主游戏中的组件，支持 1.7.2 及以上的原版与沿用官方名称的加载器。若房主所用的 Java 运行时不提供附加功能，或游戏环境经 Fabric、Quilt 等加载器重映射，则需手动对局域网开放，房间信息亦将退回仅在局域网列表中显示，游戏连接不受影响。具体原因记录在房主电脑的 `%LocalAppData%\Campfire\agent.log` 中。

### 房间未出现在联机大厅中

请确认已在多人联机页面点击 **公开到联机大厅**，且左下角显示 **已公开到联机大厅**。房间名称含有不宜公开的内容、房间遭多名玩家举报，或同一网络中公开的房间过多时，均无法公开，页面会说明具体原因，见[公开时的提示](./lobby#公开时的提示)。

### 联机组件下载失败

请检查网络连接。若正在使用代理或加速器，可以尝试将其关闭后重试。

### 提示缺少 Windows 7 更新

在 Windows 7 上使用多人联机，需要通过 Windows 更新安装 KB3063858 与 KB4474419 并重新启动。无法使用 Windows 更新时，可以在 Microsoft Update 目录中按编号手动下载。

### 如何查看详细的失败原因？

失败页面提供 **查看联机日志** 按钮。日志保存在 `%LocalAppData%\Campfire\Link\link.log`，反馈问题时请一并附上。

## 地图

### 导入的地图未出现在游戏中

请确认所启动的正是导入时选择的版本。启用版本隔离的启动器会将存档保存在版本文件夹中；游戏启动后，Campfire 依据运行中的游戏确认存档位置，如有不同，将自动迁移地图。如仍未出现，可在导入页面点击 **打开存档文件夹** 查看地图所在位置。

### 导入时未列出所需的游戏版本

Campfire 会查找默认的 `.minecraft` 文件夹、启动器旁的 `.minecraft` 文件夹，以及启动器设置中记录的游戏文件夹。游戏位于其他位置时，请点击 **添加游戏文件夹**。

### 打开地图后命令方块或红石失效

将 1.13 之前的地图导入 1.13 及以后的版本时，游戏会转换地图格式，命令与红石常因此失效。请优先选择标注为 **与地图版本相同** 的版本。

## 启动器修复

### 修复安全吗？

Campfire 只修改与下载、安装直接相关的少数方法，不添加任何联网行为。修复结果先在内存中生成并逐项校验，通过后才写入磁盘；任一步骤失败，原文件都保持不变。原文件始终以 `.bak` 备份。详见[工作原理](./how-it-works#启动器修复)。

### 提示“暂不支持修复”

说明该启动器的代码结构与已知版本不同，Campfire 无法确认修改位置。此时不会做任何修改。可以在 [GitHub Issues](https://github.com/Xocio/Campfire/issues) 中反馈启动器的版本。

### 写入文件失败

启动器可能仍在运行，或位于 `Program Files` 等受保护的文件夹。请关闭启动器后重试；仍然失败时，以管理员身份运行 Campfire。

### 修复后启动器还能更新吗？

修复会停用启动器的自动更新，以免更新后功能再次被关闭。需要升级时，请手动下载新版启动器，再运行 Campfire 检测是否需要修复。

### 如何撤销修复？

在启动器修复工具中点击 **还原**；或删除修复后的启动器，再将 `.bak` 文件改回原名。

## 其他

### Campfire 是否可能被远程控制？

不会。Campfire 自服务器接收的仅为文字与列表数据，无法更改设置、执行命令或启动程序；只有通过签名校验的更新与哈希一致的联机组件才会被运行。全部联网行为与风险边界见[联网与安全](./security)。

### 杀毒软件报毒

修改其他程序文件的工具偶尔会被误判。Campfire 完全开源，可以审阅源代码并[自行构建](https://github.com/Xocio/Campfire#从源码构建)。官方发布的文件可以通过[下载页](/download)中的 SHA-256 核对。

### 关闭窗口后 Campfire 去哪了？

若开启了 **关闭窗口时保留在通知区域**，Campfire 会继续在通知区域中运行，房间保持开启。单击图标即可返回窗口。Windows 11 可能将图标收进任务栏右侧的 **^** 溢出菜单中。

### 再次打开程序时没有出现新窗口

同一用户会话中只运行一个 Campfire。再次打开时，已在运行的窗口会被切换到前台；若它隐藏在通知区域中，也会被重新显示。

### 如何反馈问题？

请在 [GitHub Issues](https://github.com/Xocio/Campfire/issues) 中提交，并尽量附上系统版本、操作步骤，以及联机日志或截图。
