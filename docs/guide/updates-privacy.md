# 更新与隐私

更新与隐私相关的选项位于 **设置 › 常规**。

## 更新

### 检查更新与公告

正式版在启动时获取最新版本信息与公告。该请求不携带任何设备标识，所有用户收到的内容相同。可以关闭 **启动时检查更新与公告**，并在需要时点击 **检查更新** 手动检查。

### 安装更新

发现新版本后，Campfire 会先显示更新说明并征求同意。确认后：

1. 下载更新包；
2. 校验更新包的**数字签名**，只有由 Campfire 发布密钥签名的文件才会被接受；
3. 替换程序文件并自动重新启动。

若当前开启了房间，Campfire 会提前说明更新将关闭房间。若程序所在文件夹不可写入，或下载、校验失败，当前版本保持不变，Campfire 会打开下载页面供手动更新。

### 必须更新

当旧版本存在严重问题时，新版本可能被标记为必须更新。只有在签名正确的新版本已下载并通过校验后，Campfire 才会要求更新后再继续使用；若下载或校验失败，Campfire 照常可用。

::: info 从源代码构建的版本
自行构建的版本不会连接更新与公告服务，也不会发送使用统计。
:::

## 使用统计

使用统计用于了解 Campfire 的使用情况并改进软件。它**仅在你同意后发送**，拒绝不影响任何功能，也可以随时在 **设置 › 常规** 中关闭。

### 发送的内容

每台电脑每天最多发送一次，内容仅限：

- 统计标识：首次发送时随机生成，与联机使用的设备标识无关，可随时重置；
- 软件版本、Windows 版本与系统位数、.NET Framework 版本、界面语言；
- 创建房间、加入房间、修复启动器等功能的使用次数；
- 服务器根据网络来源推断的大致国家与省份。

点击 **查看发送内容** 可以看到下一次发送的完整数据。

### 不会收集的内容

IP 地址、游戏账号与 UUID、玩家名称、房间与邀请码、文件路径、硬件序列号与网卡地址。你主动公开到联机大厅的房间除外，见[联机大厅](./lobby#隐私)。

### 保存与用途

统计明细保留 90 天后自动删除，此后只保留不含统计标识的汇总数字。数据仅用于了解软件的使用情况和改进软件，不会出售或提供给第三方。

### 撤回

关闭使用统计后，Campfire 不再发送任何统计数据。点击 **重置统计标识** 后，此前发送的数据将无法再与这台电脑关联。

## 联机中的隐私

联机相关的隐私选项，包括隐藏 IP 地址、读取游戏账号与共享皮肤，见[网络与隐私](./network#隐私)。

完整的隐私说明也可以在 Campfire 的 **设置 › 常规 › 隐私说明** 中查看。Campfire 的全部联网行为见[联网与安全](./security)。
