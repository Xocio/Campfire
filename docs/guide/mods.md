# 模组同步

加入房间后，模组同步会比对本机与房主的游戏版本和模组，列出不一致之处，并一键将本机的模组调整为与房主相同。

## 房主：提供模组列表

模组同步默认开启。房间开启后，可在多人联机页面的 **工具 › 模组同步** 中随时 **开启** 或 **关闭**；关闭后立即停止提供模组列表与文件。也可在 **设置 › 联机 › 模组** 中设定：

| 选项 | 说明 |
| --- | --- |
| **允许玩家同步我的模组** | 房间内的玩家可查看你的游戏版本、模组加载器，以及各模组的名称与版本，并据此同步 |
| **允许玩家从我这里下载模组** | 官方源未收录的模组经联机网络自你的电脑传送，会占用上传带宽。仅模组文件夹中列出的文件可被下载 |

## 玩家：同步模组

1. 加入房间后，在多人联机页面的 **工具 › 模组同步** 中点击 **同步**，打开模组同步页面。
2. 页面上方显示房主的游戏版本、加载器与模组数量。
3. 在 **本机版本** 中选择与房主相同的已安装版本。未列出时，可点击 **添加游戏文件夹**；仍未找到时，请先在启动器中安装该版本。
4. 查看差异列表：

   | 标记 | 含义 |
   | --- | --- |
   | **缺少** | 房主安装了，本机没有 |
   | **版本不同** | 双方都有，版本不一致 |
   | **房主未安装** | 本机有，房主没有。勾选 **移除房主未安装的模组** 后将其移入备份文件夹 |

   小地图、光影等仅需一方安装的模组不计入差异。

5. 选择 **下载来源**，点击 **同步模组**。

| 下载来源 | 说明 |
| --- | --- |
| **优先官方源** | 自 Modrinth 与 CurseForge 下载与房主完全相同的文件，官方源未收录或不允许第三方下载的再自房主获取 |
| **仅官方源** | 只从 Modrinth 与 CurseForge 下载，无法获取的模组会在完成后列出，需自行安装 |
| **全部从房主获取** | 全部文件经联机网络自房主的电脑传送 |

::: warning 请仅在信任房主时自房主获取模组
模组是随游戏运行的程序。需要自房主获取文件时，Campfire 会先告知文件数量并征得同意。
:::

## 安全保障

- 无论来自哪一来源，文件的大小与 SHA-1 均须与房主所列一致，否则即被丢弃。
- 全部文件下载并校验完毕后，才会改动模组文件夹。
- 被替换或移除的模组移入备份文件夹，不会被删除，可在完成后点击 **打开备份文件夹** 找回。
- 房主只能按列表提供模组文件夹中的文件，玩家无法借此读取房主的其他文件。

更完整的说明见[联网与安全](./security#模组同步)。

## 常见提示

| 提示 | 处理 |
| --- | --- |
| 房主未开启模组同步 | 请房主在 **工具 › 模组同步** 中开启 |
| 未找到与房主相同的游戏版本 | 先在启动器中安装与房主相同的版本，再返回此页 |
| 该版本的游戏正在运行 | 关闭游戏后再同步 |
| 模组文件夹中的文件正被占用 | 关闭游戏后重试 |
| 房主未提供该文件 | 房主可能已关闭模组下载或更换了模组 |
| 下载的文件与房主的文件不符，已丢弃 | 请重试，或改用其他下载来源 |
| 已离开房间，无法再从房主处获取模组 | 重新加入房间后再同步 |
