# 联机大厅

联机大厅汇集了 Campfire 用户公开的房间。玩家可在此发现正在进行的世界并加入其中；房主亦可将自己的房间公开至大厅，迎接更多同伴。

在 **主页** 点击 **联机大厅** 即可进入。

::: info
联机大厅由 Campfire 服务提供，仅正式版可用。从源代码构建的版本不提供大厅，邀请码联机不受影响。
:::

## 浏览与加入

大厅列出当前全部公开房间，每个房间显示以下信息：

| 信息 | 说明 |
| --- | --- |
| 图标与名称 | 由房主设定 |
| 房主与地图 | 房主的玩家名称与世界名称 |
| 游戏版本与标签 | 加入前请确认游戏版本一致 |
| 玩家 | 当前人数与人数上限 |
| 开启时间 | 房间公开至今的时长 |

页面顶部支持按房间名称、房主或地图检索，并可按游戏版本筛选。列表会定期自动刷新，亦可点击 **刷新** 立即更新。

选择房间即进入 **房间详情**，其中列出游戏版本、大致地区与开启时间。点击 **加入房间** 后，Campfire 自大厅领取该房间的邀请码并完成加入，其后的流程与凭邀请码加入完全一致，见[创建与加入房间](./multiplayer)。

::: tip 设有密码的房间
标有 **需要密码** 的房间，需输入房主提供的密码方可加入。密码由服务器校验，验证通过后才会发放邀请码。
:::

::: warning 加入前请确认游戏版本
请以与房间相同的游戏版本启动游戏。加入后，从多人游戏列表底部的局域网世界进入。
:::

已处于房间中时无法加入其他房间，请先离开或关闭当前房间。

## 公开房间

1. 按照[创建与加入房间](./multiplayer)中的步骤创建房间。
2. 房间就绪后，在多人联机页面点击 **公开到联机大厅**。
3. 填写公开信息：

   | 选项 | 说明 |
   | --- | --- |
   | **房间名称** | 必填，默认为“玩家名 的世界”。含有不宜公开的内容时无法提交 |
   | **房间图标** | 可选。可选用 PNG 或 JPG 图片，或直接使用地图自带的图标 |
   | **房间密码** | 可选。留空即任何人均可加入 |
   | **标签** | 至多 3 个，例如生存、建筑、红石、小游戏 |
   | **显示所在省份** | 是否在大厅中显示服务器推断的大致地区 |

4. 点击 **公开房间**。

游戏版本与世界名称由 Campfire 从运行中的游戏读取，无需手动填写；读取失败时，房间仍可公开。

房间公开期间，多人联机页面左下角显示其公开状态，Campfire 每隔数分钟向大厅更新一次人数。点击 **取消公开** 可随时撤下；关闭房间时亦会自动取消公开。

::: warning 关于 IP 地址
与你直连的玩家可以获知你的 IP 地址。如有顾虑，可在联机设置中开启[隐藏我的 IP 地址](./network#隐藏我的-ip-地址)。房间公开后，你仍可随时[移出或拉黑](./room)任何玩家。
:::

## 举报

如认为某个房间的名称或内容不当，可在房间详情中点击 **举报**。经多名玩家举报后，该房间将自大厅隐藏。

## 公开时的提示

| 提示 | 原因与处理 |
| --- | --- |
| 房间名称含有不允许公开的内容 | 修改房间名称后重试 |
| 该房间已由其他玩家公开到联机大厅 | 同一邀请码仅能公开一次 |
| 操作过于频繁 | 同一网络中公开的房间过多，或操作过于频繁，请稍后重试 |
| 联机大厅的房间已满 | 请稍后重试 |
| 当前版本无法公开房间 | 请先更新 Campfire |
| 房间因多名玩家举报，已从大厅隐藏 | 同一邀请码在一段时间内无法再次公开 |

## 隐私

仅当你将房间公开至大厅时，Campfire 才会发送房间信息，包括房间名称、邀请码、玩家名称、游戏版本、地图名称、标签与人数，以及一个大厅专用的随机编号。该编号与联机设备标识、统计标识均无关联。

服务器仅保存房间密码的摘要，IP 地址亦仅以加盐摘要的形式保存，用于限制发布频率与处理违规。取消公开或关闭房间后，房间即刻自大厅移除，相关记录于一天内删除。完整说明见[联网与安全](./security#联机大厅)。
