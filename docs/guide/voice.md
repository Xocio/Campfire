# 语音聊天

Campfire 借助开源模组 Simple Voice Chat 为房间提供语音。房主开启语音后，Campfire 会为游戏安装并启用该模组，语音经联机网络加密传输，无需端口映射；房间内安装同一模组的玩家进入世界后即可相互交谈。

## 开始之前

- 语音需要模组加载器：请使用 Fabric、Forge、NeoForge 或 Quilt 版本的游戏，原版无法使用。
- 玩家须拥有与房主游戏版本及模组加载器相同的本机版本。
- 语音适用于由房主游戏开放的局域网世界，专用服务器暂不支持开启语音。
- 语音默认关闭，仅在房主开启后提供。

## 房主：开启语音

1. 创建房间后，在多人联机页面的 **工具** 卡片中找到 **语音**，点击 **开启**。
2. 若游戏中尚未安装该模组，Campfire 会从 Modrinth 下载适用于该游戏版本与加载器的最新正式版，校验后放入游戏的模组文件夹；已停用的同一模组会被重新启用。
3. 新装的模组需要重新启动游戏才会生效。Campfire 会弹出提示，请关闭并重新启动游戏，进入同一个世界。

重新启动游戏期间，房间保持开启，邀请码不变，房间内的玩家无需重新加入。10 分钟内回到同一个世界，Campfire 会自动对局域网开放并恢复房间；未开启自动对局域网开放时，请手动开放。

**语音** 一栏会显示当前状态：

| 状态 | 说明 |
| --- | --- |
| 未开启 | 点击 **开启** 后为游戏安装语音模组 |
| 正在下载语音模组 | 正在自 Modrinth 下载并校验 |
| 已安装，重新启动游戏并进入世界后生效 | 请重新启动游戏，房间会保持开启 |
| 已开启 | 游戏中的语音服务已运行，安装了语音模组的玩家可相互交谈 |

点击 **关闭** 后，Campfire 立即停止转发语音，房间内玩家的语音随即中断。模组仍保留在游戏中，不再需要时可在启动器中自行移除。

## 玩家：安装语音模组

房主开启语音后，玩家的多人联机页面会在 **工具 › 语音** 中提示安装：

1. 点击 **安装**，确认要安装的模组与目标版本。
2. Campfire 优先下载与房主完全相同的文件；Modrinth 未收录时，改为适用于该游戏版本的最新正式版。文件仅写入与房主游戏版本及加载器相同的本机版本的模组文件夹。
3. 启动该版本的游戏并进入房主的世界即可交谈；安装时游戏已在运行的，请重新启动游戏。

| 状态 | 说明 |
| --- | --- |
| 房主未开启语音 | 房主开启后才能使用 |
| 房主已开启语音，将在房主重新启动游戏后可用 | 房主的游戏尚未加载语音模组 |
| 房主已开启语音，为版本 … 安装语音模组后即可使用 | 点击 **安装** |
| 未找到与房主游戏版本及模组加载器相同的版本 | 请先在启动器中安装相同的版本 |
| 本机 UDP 端口 … 已被占用 | 请关闭占用该端口的程序后重试 |
| 已就绪 | 进入房主的世界后即可语音交流 |

进入世界后，按键、麦克风与音量均在模组的设置界面中调整，默认按 **V** 打开。

## 在联机大厅中

提供语音的房间在联机大厅中带有 **语音** 标签，房间详情中也会注明，加入后在房间页面安装语音模组即可使用。

## 隐私

语音数据由模组在玩家与房主之间传输，并经联机网络加密。Campfire 不读取、不保存任何语音内容。房主仅在语音服务运行时向房间开放其所用的一个 UDP 端口，关闭语音后立即撤销。详见[联网与安全](./security#语音)。
