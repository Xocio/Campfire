# 启动器修复

部分启动器在新版本中停用了游戏下载、加载器安装与整合包安装，或按所在地区关闭了这些功能。启动器修复工具可以恢复这些功能，同时保证修改范围最小、过程可验证、结果可还原。

## 可恢复的功能

| 项目 | 说明 |
| --- | --- |
| **Minecraft 版本列表** | 恢复“下载”页的游戏版本列表，以及游戏与 Mod 加载器的安装 |
| **手动安装整合包** | 恢复“安装整合包”按钮的文件选择功能 |
| **整合包安装** | 恢复 CurseForge、Modrinth、MCBBS、HMCL、MMC 等格式整合包的安装 |
| **地区限制** | 解除按地区关闭的下载、安装与文件补全 |
| **停用自动更新** | 防止启动器自动更新后再次关闭上述功能 |

Campfire 会先检测所选启动器，只列出与其相关的项目，并逐项标明 **待修复**、**已恢复**、**无需修复** 等状态。

## 修复步骤

1. **关闭启动器。** 启动器运行时其程序文件被占用，Campfire 会提示先将其关闭。
2. 打开 Campfire，在 **工具** 中选择 **启动器修复工具**。
3. 选择启动器。Campfire 会自动查找自身所在文件夹中的启动器；也可以点击 **选择文件**，或直接将启动器文件拖入窗口。
4. 查看检测结果与 **修复内容**，确认后点击 **一键修复**。
5. 修复完成后，点击 **打开启动器** 即可直接使用。

## 检测结果

| 提示 | 含义 |
| --- | --- |
| 已关闭下载功能，可以一键修复 | 检测到受影响的版本，可直接修复 |
| 已按地区关闭下载功能，可以一键修复 | 检测到地区限制，可直接解除 |
| 下载功能已恢复 | 该启动器此前已由 Campfire 修复 |
| 下载功能正常，无需修复 | 该版本不受影响，Campfire 不会做任何修改 |
| 代码结构与已知版本不同，暂不支持修复 | 无法确认修改位置，Campfire 不会做任何修改 |

只要无法确定修改是安全的，Campfire 就不会写入文件。

## 备份与还原

修复前的启动器会以 `.bak` 为后缀保存在同一文件夹中，例如 `启动器.exe.bak`。需要恢复时，可任选一种方式：

- 在启动器修复工具中点击 **还原**。Campfire 会先确认备份文件是受支持的启动器，再执行还原。
- 手动删除修复后的启动器，再将 `.bak` 文件改回原名。

## 关于自动更新

为防止启动器在自动更新后再次关闭上述功能，修复会同时停用启动器的自动更新。需要升级启动器时：

1. 手动下载新版启动器并替换旧文件；
2. 再次运行 Campfire，检测新版是否需要修复。

## 安全性

- **最小修改。** 只改动与上述功能直接相关的少数方法，不添加任何联网行为。
- **精确定位。** 修改位置依据方法名称与代码特征确定，而非固定的文件偏移，因此启动器的后续小版本通常无需更新 Campfire 即可修复。
- **先验证后写入。** 修复结果先在内存中生成，重新加载并逐项校验通过后才写入磁盘；任一步骤失败，原文件都保持不变。
- **仅在本机进行。** 修复过程不上传、不下载任何文件。
