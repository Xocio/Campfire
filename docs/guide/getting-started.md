# 安装与上手

## 准备

### 系统要求

- Windows 7 SP1、8、8.1、10 或 11。
- .NET Framework 4.8。Windows 10 与 11 已内置；Windows 7 与 8 如未安装，请从[微软官方网站](https://dotnet.microsoft.com/download/dotnet-framework/net48)下载。
- 在 Windows 7 上使用多人联机，还需通过 Windows 更新安装 **KB3063858** 与 **KB4474419** 并重新启动。无法使用 Windows 更新时，可在 Microsoft Update 目录中按编号手动下载。

### 下载

前往[下载页](/download)获取最新版本。中国大陆用户建议使用国内直链；也可以从 [GitHub Releases](https://github.com/Xocio/Campfire/releases/latest) 下载。

## 首次运行

1. 将 `Campfire.exe` 放到任意文件夹并双击运行。若需使用启动器修复，建议将其放在启动器所在的文件夹中，Campfire 会自动识别。
2. 首次启动时会出现新手引导，用约半分钟介绍主页、地图、工具与设置。可随时跳过，之后在 **设置 › 关于** 中再次查看。
3. 正式版会询问是否发送匿名使用统计。该选项完全自愿，拒绝不影响任何功能，详见[更新与隐私](./updates-privacy)。

::: tip 单实例运行
同一 Windows 用户会话中只会运行一个 Campfire。再次打开程序时，已在运行的窗口会被切换到前台，房间不受影响。
:::

## 第一次联机

以下为最简流程，完整说明见[创建与加入房间](./multiplayer)。

**房主**

1. 在 **主页** 点击 **创建房间**。
2. 启动游戏并进入单人世界，Campfire 会自动将其对局域网开放。
3. 房间随即创建，邀请码复制到剪贴板，发送给好友即可；亦可将房间公开至[联机大厅](./lobby)。

**好友**

1. 复制房主发来的邀请码后打开 Campfire，主页将提示是否加入该房间；亦可在 **主页** 点击 **加入房间** 并粘贴，或在 **联机大厅** 中选择房间。
2. 连接完成后，在游戏的 **多人游戏** 列表底部找到房间条目，双击进入。

::: warning 首次联机需下载联机组件
第一次创建或加入房间时，Campfire 会下载约 14 MB 的联机组件，并逐个文件校验完整性。Windows 防火墙可能询问是否允许其访问网络，选择 **允许** 有助于建立直连。
:::

## 第一次修复启动器

1. 关闭启动器。
2. 打开 Campfire，在 **工具** 中选择 **启动器修复工具**。Campfire 会自动查找同一文件夹中的启动器，也可以点击 **选择文件** 或直接将启动器拖入窗口。
3. 查看 **修复内容** 中各项的状态，确认后点击 **一键修复**。

修复完成后即可正常启动。原文件以 `.bak` 为后缀备份在同一文件夹中，随时可通过 **还原** 恢复。详见[启动器修复](./launcher-repair)。

## 数据位置

Campfire 的设置、联机组件、日志与缓存均保存在 `%LocalAppData%\Campfire`。程序文件本身可以随意移动或替换，不会影响已保存的设置。

| 路径 | 内容 |
| --- | --- |
| `settings.ini` | 全部设置 |
| `EasyTier\` | 联机组件 |
| `Link\link.log` | 联机日志，用于排查问题 |
| `Link\blocked.json` | 房主的黑名单 |
| `Link\heads\` | 正版玩家皮肤头像缓存，保留一天 |
| `agent.log` | 游戏内组件的日志 |
| `mappings\` | 游戏内组件使用的 Mojang 名称映射表 |
| `downloads\maps\` | 下载的地图文件，一周未使用后自动删除 |

在 **联机设置 › 数据** 中可以直接打开该文件夹，或删除联机组件以便下次重新下载。
