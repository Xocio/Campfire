# Personalization

These options live in **Settings › Personalize**. Every change applies immediately.

## Theme mode

| Mode | Description |
| --- | --- |
| **Follow system** | Switches with the Windows light or dark setting |
| **Light** | Always light |
| **Dark** | Always dark |

## Color source

Campfire derives its whole palette, including buttons, accents, backgrounds and text levels, from a single theme color. The theme color can come from three places:

### Pick a color

Choose from the preset swatches, or type a six-digit hex value such as `#E2680C` and press Enter. The default campfire orange is `#E2680C`.

### Monet colors

Campfire takes the most characteristic color from your desktop wallpaper and builds the whole palette from it. The palette follows when the wallpaper changes, and **Read again** refreshes it immediately. If the wallpaper has no sufficiently vivid color, the Windows accent color is used instead.

### Windows accent color

Uses the accent color from Windows personalization settings.

## Palette style

The same theme color can produce palettes of different character:

| Style | Character |
| --- | --- |
| **Standard** | Close to the theme color with balanced contrast. Suits most cases |
| **Vibrant** | As colorful as the screen can show |
| **Playful** | Shifts the hue away from the theme color for a livelier look |
| **Soft** | Mostly gray with a touch of the theme color |
| **Monochrome** | Gray only, without any color |
| **Faithful** | Keeps the theme color itself as closely as possible |

Palettes are computed in a perceptually uniform color space, so text keeps steady contrast against its background whatever color you choose.

## Animation

**Enable animations** controls the transitions shown when pages change, dialogs open or the theme changes. When off, every change takes effect immediately.

## Language

Campfire speaks Simplified Chinese and English and follows the system language on first start. Switch it in **Settings › General › Language**, or with the language button in the title bar.

## Notification area

| Option | Description |
| --- | --- |
| **Show Campfire in the notification area** | The icon shows the multiplayer status, with the flame lit while a room is open. Click to open the window; right-click to see the room, copy the invite code or exit |
| **Keep running in the notification area when closed** | The window's close button only hides the window and the room stays open. Use the notification area menu to exit |

::: tip The icon does not appear
Windows 11 places icons of new programs in the overflow menu by default. Click **^** at the right of the taskbar to find it, or set it to always show in the Windows taskbar settings.
:::
