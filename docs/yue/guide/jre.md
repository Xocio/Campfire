# JRE 啟用工具

部分啟動器會將唔含 `javac.exe` 嘅 Java，即 JRE，默認標記為停用；Java 9 及以上嘅 JRE 更係始終冇辦法選擇。呢使得僅安裝咗 JRE 嘅電腦冇辦法用其啟動遊戲。JRE 啟用工具可以解除呢一限制，使 JRE 與 JDK 一樣默認可用。

該工具獨立於啟動器修復，兩者可以單獨使用，備份都互唔影響。

## 使用方法

1. 關閉啟動器。
2. 喺 Campfire 嘅 **工具** 中選擇 **JRE 啟用工具**。
3. Campfire 會自動查搵同一文件夾中嘅啟動器；亦可以按 **選擇文件** 或將其拖入窗口。
4. 確認 **處理內容** 中顯示 **待處理** 後，按 **啟用 JRE**。

處理完成後，新發現或新導入嘅 JRE 會默認啟用。

::: warning 已被停用嘅 JRE 需手動啟用一次
處理之前已被啟動器記錄為「停用」嘅 JRE，唔會自動恢復。請喺啟動器嘅 Java 列表中將其手動啟用一次。
:::

## 處理內容

工具只移除與 JRE 相關嘅兩項限制：

- 唔再因缺少 `javac.exe` 而默認停用 Java；
- 唔再禁止選擇 Java 9 及以上嘅 JRE。

「系統位數必須與 Java 位數一致」嘅檢查保持唔變，以免選中冇辦法運行嘅 Java。整個改動僅涉及極少量字節，文件大小與打包佈局均保持原樣，無需重新打包。

## 檢測結果

| 提示 | 含義 |
| --- | --- |
| 默認停用 JRE，可予以解除 | 可以處理 |
| 已經可以使用 JRE | 此前已處理過 |
| 此版本唔存在 JRE 限制 | 無需處理 |
| 所選文件並非受支持嘅啟動器 | 該啟動器本身唔存在此限制 |
| 代碼結構與已知版本不同，暫唔支持處理 | 冇辦法確認修改位置，唔會做任何修改 |

## 備份與還原

處理前嘅啟動器保存為同一文件夾中嘅 `.jre.bak` 文件，與啟動器修復產生嘅 `.bak` 相互獨立。按 **還原** 就可以恢復處理前嘅狀態。
