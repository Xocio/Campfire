# 網絡與隱私

本頁介紹聯機設置中嘅各個選項。聯機設置位於 **設置 › 聯機**，亦可從主頁嘅 **聯機設置** 磁貼，或按標題欄嘅中轉服務器指示燈打開。

::: info
設置更改會即時保存，並喺下次創建或加入房間時生效。
:::

## 連接方式

Campfire 喺玩家之間建立一個加密嘅虛擬網絡，遊戲數據喺其中傳輸。連接分為兩種：

| 方式 | 數據路徑 | 特點 |
| --- | --- | --- |
| **直連** | 玩家之間點對點傳輸 | 延遲最低，接近本地網絡 |
| **中轉** | 經由中轉節點轉發 | 適用於雙方網絡限制均較嚴嘅情況，延遲有所增加 |

Campfire 始終優先嚐試直連。能否直連主要取決於雙方嘅網絡類型：多人聯機頁面會顯示本機嘅 NAT 類型（公網、NAT1 至 NAT4）以及是否具備 IPv6。雙方都具備 IPv6 時，幾乎總能建立直連；雙方同為 NAT4 時，通常只能經由中轉。

**聯機節點**僅用於幫助玩家互相發現，遊戲數據唔會經過 Campfire 嘅服務器。只有喺容許中轉且直連失敗時，遊戲數據先會經中轉節點傳輸。

聯機期間各方能睇到邊啲信息、點解聯機組件冇辦法訪問你電腦上嘅其他服務，見[聯網與安全](./security#多人聯機)。連接出現問題時，可先運行[聯機診斷](./room#聯機診斷)。

## 房間

| 選項 | 說明 |
| --- | --- |
| **玩家名稱** | 喺房間中顯示嘅名稱。留空時使用遊戲中嘅名稱 |
| **房間顯示名稱** | 加入房間後，多人遊戲列表中顯示嘅房間名稱 |
| **本地端口** | 加入房間時，本機用於連接房主遊戲嘅端口。通常無需設置，留空即自動選擇 |
| **尋搵房主時限** | 加入房間時等待房主響應嘅最長時間，可選 30、60 或 120 秒 |
| **創建房間後自動複製邀請碼** | 房間就緒後立即將邀請碼寫入剪貼板 |
| **自動識別剪貼板中嘅邀請碼** | 複製邀請碼後，主頁直接提示加入 |
| **創建房間時自動對局域網開放** | 創建房間後，進入單人世界時由 Campfire 代為對局域網開放，見[自動對局域網開放](./multiplayer#自動對局域網開放) |
| **開房前備份存檔** | 開啟房間時將喺度遊玩嘅世界壓縮保存一份，每個世界保留最近 5 份，超過 2 GB 嘅世界唔備份，見[存檔備份](./room#存檔備份) |

## 網絡

### 直連失敗時容許通過中轉節點連接

開啟後，直連失敗時經由中轉節點繼續連接，會增加延遲。關閉後，直連失敗將冇辦法加入房間。

### 容許同一局域網中嘅其他設備通過本機加入房間

開啟後，與你處於同一真實局域網嘅其他設備亦能喺其局域網世界列表中睇到房間，並通過本機加入。關閉後，房間僅出依家本機嘅局域網世界列表中。

## 中轉服務器

中轉服務器幫助玩家互相發現，並喺直連失敗時轉發數據。設置中列出咗全部內置服務器及其地區、提供者與實測延遲，可逐個啟用或停用；按 **測試延遲** 可重新測量。個別服務器限制中轉速度，會喺列表中註明。

聯機雙方須至少啟用一個相同嘅服務器，先能搵到彼此。以上服務器均由社區成員無償提供。

### 自定義節點

可以填寫自己嘅節點，支持 `tcp`、`udp`、`ws`、`wss`、`quic`、`http`、`https`、`txt` 與 `srv` 地址，多個地址之間以空格分隔，例如：

```
tcp://example.com:11010 wss://example.com:443
```

無效嘅地址會喺保存時提示，並喺聯機時被忽略。停用全部內置服務器後，房間中嘅所有玩家都必須使用相同嘅自定義節點先能搵到彼此。

## 隱私

### 隱藏我嘅 IP 地址

開啟後，全部數據都經由中轉節點傳輸，房主與其他玩家無從得知你嘅 IP 地址，但中轉節點嘅運營方仍可睇到。該選項會顯著增加延遲，而且只接受直連嘅玩家將冇辦法與你連接，因此開啟前 Campfire 會再次確認。

### 讀取遊戲中嘅玩家名稱與賬號類型

僅讀取運行中游戲嘅玩家名稱、UUID 與賬號類型，用於顯示名稱與識別正版玩家。唔讀取、唔保存任何登錄憑據。

### 顯示正版玩家嘅皮膚頭像

開啟後，你嘅正版賬號 UUID 會共享畀房間內嘅其他玩家，雙方通過 Mojang 官方服務獲取皮膚並生成頭像。

### 向其他玩家顯示軟件版本

關閉後，其他玩家只能睇到你喺使用 Campfire，睇唔到具體版本。

### 重置設備標識

每台電腦喺聯機網絡中有一個隨機生成嘅設備標識。重置後，其他玩家會將呢台電腦視為一台新設備。需要喺冇開啟房間時進行。

## 黑名單

列出被你拉黑嘅玩家與拉黑時間，可逐個解除。被拉黑嘅玩家冇辦法加入你創建嘅房間，見[移出與拉黑](./room#移出與拉黑)。

## 數據

| 操作 | 說明 |
| --- | --- |
| **打開數據文件夾** | 打開 `%LocalAppData%\Campfire`，其中包含設置、聯機日誌與黑名單 |
| **打開備份文件夾** | 打開 `%LocalAppData%\Campfire\backups\worlds`，其中保存住開房前嘅存檔備份 |
| **清除頭像緩存** | 刪除本地緩存嘅皮膚頭像，下次顯示時重新獲取 |
| **刪除聯機組件** | 刪除已下載嘅聯機組件，下次聯機時重新下載並校驗 |

刪除聯機組件需要喺冇開啟房間時進行。
