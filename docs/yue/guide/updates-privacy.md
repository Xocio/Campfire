# 更新與隱私

更新與隱私相關嘅選項位於 **設置 › 常規**。

## 更新

### 檢查更新與公告

正式版喺啟動時獲取最新版本信息與公告。該請求唔攜帶任何設備標識，所有用戶收到嘅內容相同。可以關閉 **啟動時檢查更新與公告**，並喺需要時按 **檢查更新** 手動檢查。

### 安裝更新

發現新版本後，Campfire 會先顯示更新說明並徵求同意。確認後：

1. 下載更新包；
2. 校驗更新包嘅**數字簽名**，只有由 Campfire 發佈密鑰簽名嘅文件先會被接受；
3. 替換程序文件並自動重新啟動。

若當前開啟咗房間，Campfire 會提前說明更新將關閉房間。若程序所在文件夾不可寫入，或下載、校驗失敗，當前版本保持唔變，Campfire 會打開下載頁面供手動更新。

### 必須更新

當舊版本存在嚴重問題時，新版本可能被標記為必須更新。只有喺簽名正確嘅新版本已下載並通過校驗後，Campfire 先會要求更新後再繼續使用；若下載或校驗失敗，Campfire 照常可用。

::: info 從源代碼構建嘅版本
自行構建嘅版本唔會連接更新與公告服務，都唔會發送使用統計。
:::

## 使用統計

使用統計用於瞭解 Campfire 嘅使用情況並改進軟件。佢**僅喺你同意後發送**，拒絕唔影響任何功能，亦可以隨時喺 **設置 › 常規** 中關閉。

### 發送嘅內容

每台電腦每天最多發送一次，內容僅限：

- 統計標識：首次發送時隨機生成，與聯機使用嘅設備標識無關，可隨時重置；
- 軟件版本、Windows 版本與系統位數、.NET Framework 版本、界面語言；
- 創建房間、加入房間、修復啟動器等功能嘅使用次數；
- 服務器根據網絡來源推斷嘅大致國家與省份。

按 **查看發送內容** 可以睇到下一次發送嘅完整數據。

### 唔會收集嘅內容

IP 地址、遊戲賬號與 UUID、玩家名稱、房間與邀請碼、文件路徑、硬件序列號與網卡地址。你主動公開到聯機大廳嘅房間除外，見[聯機大廳](./lobby#隱私)。

### 保存與用途

統計明細保留 90 天后自動刪除，此後只保留唔含統計標識嘅彙總數字。數據僅用於瞭解軟件嘅使用情況同改進軟件，唔會出售或提供畀第三方。

### 撤回

關閉使用統計後，Campfire 唔再發送任何統計數據。按 **重置統計標識** 後，此前發送嘅數據將冇辦法再與呢台電腦關聯。

## 聯機中嘅隱私

聯機相關嘅隱私選項，包括隱藏 IP 地址、讀取遊戲賬號與共享皮膚，見[網絡與隱私](./network#隱私)。

完整嘅隱私說明亦可以喺 Campfire 嘅 **設置 › 常規 › 隱私說明** 中查看。Campfire 嘅全部聯網行為見[聯網與安全](./security)。
