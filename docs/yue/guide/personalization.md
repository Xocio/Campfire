# 個性化

個性化選項位於 **設置 › 個性化**。所有更改即時生效。

## 主題模式

| 模式 | 說明 |
| --- | --- |
| **跟隨系統** | 隨 Windows 嘅淺色或深色設置自動切換 |
| **淺色** | 始終使用淺色界面 |
| **深色** | 始終使用深色界面 |

## 顏色來源

Campfire 嘅整套界面配色由一種主題色生成，包括按鈕、強調色、背景與文本嘅層次。主題色可以來自三處：

### 自選顏色

從預設色板中選取，或輸入形如 `#E2680C` 嘅六位十六進制色值後按回車應用。默認嘅篝火橙即為 `#E2680C`。

### 莫奈取色

自動從桌面壁紙中提取最具代表性嘅顏色，並據此生成整套配色。更換壁紙後，配色會隨之更新；亦可以按 **重新取色** 立即刷新。若壁紙嘅顏色唔夠鮮明，Campfire 會改用 Windows 主題色。

### Windows 主題色

沿用 Windows 個性化設置中嘅主題色。

## 配色風格

同一種主題色可以生成不同性格嘅配色：

| 風格 | 特點 |
| --- | --- |
| **標準** | 貼近主題色，明暗搭配均衡，適合大多數情況 |
| **鮮豔** | 喺屏幕可顯示嘅範圍內儘量提高飽和度 |
| **多彩** | 喺主題色嘅基礎上偏移色相，呈現更活潑嘅配色 |
| **柔和** | 以灰色為主，僅保留少量主題色 |
| **單色** | 完全使用灰色，唔帶任何色彩 |
| **原色** | 儘量保留主題色本身嘅色彩與飽和度 |

配色喺感知均勻嘅色彩空間中計算，因此無論選擇何種顏色，文本與背景之間都能保持穩定嘅對比度。

## 動畫

**啟用界面動畫** 控制頁面切換、彈窗與主題變更時嘅過渡動效。關閉後，所有界面變化即時完成。

## 語言

Campfire 提供簡體中文與 English 兩種界面語言，首次啟動時跟隨系統語言。可以喺 **設置 › 常規 › 語言** 中切換，亦可以按標題欄上嘅語言按鈕快速切換。

## 通知區域

| 選項 | 說明 |
| --- | --- |
| **喺通知區域顯示 Campfire 圖標** | 以圖標呈現聯機狀態，房間開啟期間火焰常亮。按圖標展開窗口，右鍵查看房間、複製邀請碼或退出 |
| **關閉窗口時保留喺通知區域** | 按窗口嘅關閉按鈕僅隱藏窗口，房間保持開啟。需要退出時，請使用通知區域圖標的菜單 |

::: tip 圖標冇出現
Windows 11 默認會將新程序嘅圖標收進通知區域嘅溢出菜單中。按任務欄右側嘅 **^** 就可以搵到；亦可以喺 Windows 嘅「任務欄設置」中將其設為始終顯示。
:::
