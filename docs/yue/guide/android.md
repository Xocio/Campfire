# Android 版

Campfire Android 版令喺手機或平板上玩 Minecraft Java 版嘅玩家都可以創建同加入房間。佢同桌面版使用同一套聯機協議，手機同電腦上嘅玩家可以進入同一個房間，邀請碼同聯機大廳喺兩邊通用。

## 系統要求

- Android 7.0 及以上版本。
- 64 位 ARM 處理器，近年嘅手機同平板都符合呢個條件。
- 一款可以運行 Minecraft Java 版嘅 Android 啟動器。Campfire 作用於正在運行嘅遊戲，唔限定啟動器。

## 下載與安裝

1. 喺[下載頁](/yue/download#android-版)下載 `Campfire.apk`。中國大陸用戶建議使用國內直鏈。
2. 打開下載咗嘅文件。系統詢問係咪容許安裝未知來源應用時，為瀏覽器或文件管理器開啟該權限，再繼續安裝。
3. 首次打開時，Campfire 會依次檢查系統版本、通知、後台運行同局域網訪問，並說明每一項嘅用途。

::: tip 後台運行
遊戲喺前台運行時，Campfire 需要喺後台保持房間連接。請容許 Campfire 喺後台運行，並喺系統嘅電池設置中將佢設為不受限制。房間開啟期間，通知欄會持續顯示房間狀態，可以喺通知中複製邀請碼或關閉房間。
:::

## 界面概覽

| 標籤頁 | 內容 |
| --- | --- |
| 主頁 | 創建房間、加入房間、目前房間狀態同聯機步驟；卡片可以長按拖動排序，亦可以喺主頁關閉 |
| 大廳 | 瀏覽聯機大廳中公開嘅房間 |
| 設置 | 聯機設置：玩家、網絡、隱私、遊戲文件夾、房間同診斷 |

主頁右上角嘅按鈕通往 **應用設置**，入面包含主題設置、語言、更新同公告、支持項目同關於。

## 創建房間

1. 喺 **主頁** 點擊 **創建房間**，再點擊 **開始**。
2. 返回啟動器，進入單人世界，並喺遊戲菜單中選擇 **對局域網開放**。
3. 連接 Wi-Fi 時，Campfire 會自動發現該世界並開啟房間；使用流動數據時，請改用 **手動輸入端口**，填寫遊戲聊天欄中顯示嘅端口號。
4. 房間開啟後，點擊 **複製邀請碼** 或 **分享**，將邀請碼發送俾其他玩家。

::: warning 需要手動對局域網開放
Android 系統唔容許一個應用讀取或修改另一個應用嘅運行狀態，所以 Android 版無法好似桌面版咁自動對局域網開放世界，亦唔會喺遊戲聊天欄同 Tab 列表中顯示房間信息。退出世界後，房間會自動關閉。
:::

房間頁嘅 **工具** 卡片包含 **房間設置**、**公開到聯機大廳**、**白名單**、**語音** 同 **聯機診斷**；喺玩家列表中可以將玩家移出房間或添加至白名單。房間名稱、人數上限同公告嘅說明見[房間管理](./room)。

## 加入房間

1. 複製房主發嚟嘅邀請碼後打開 Campfire，應用會詢問係咪加入該房間；亦可以喺 **主頁** 點擊 **加入房間**，貼上邀請碼或整段聊天訊息。
2. 連接完成後，打開啟動器進入遊戲，喺 **多人遊戲** 列表底部搵到 **Campfire 聯機房間**，點擊進入。

邀請碼以 `U/` 開頭，共四組字符，同桌面版完全相同。房主使用正版賬號時，請由局域網世界條目進入，而唔係直接連接房間頁中顯示嘅地址。

## 聯機大廳

**大廳** 標籤頁列出所有公開嘅房間，桌面版同 Android 版嘅房間都會顯示喺入面。房間設有密碼時，點擊 **加入房間** 後需要輸入密碼。認為房間嘅名稱或內容不當時，可以喺房間詳情中舉報。

### 公開房間

房主可以喺房間頁嘅 **工具** 卡片中打開 **公開到聯機大廳**，填寫房間介紹同密碼，揀最多 3 個標籤，再點擊 **公開**。房間名稱沿用房間設置中嘅名稱，大廳顯示佢嘅頭 24 個字；遊戲版本同世界名稱由 Campfire 自動讀取。公開後，房間嘅人數同語音狀態會隨時同步到大廳；房間關閉後自動從大廳移除，亦可以隨時點擊 **取消公開**。

## 語音

房主喺房間頁開啟語音後，Campfire 會為遊戲安裝語音模組 Simple Voice Chat，並為玩家轉發語音數據。語音需要以下準備：

- **授權遊戲文件夾**：喺 **設置 › 遊戲文件夾** 中授權啟動器嘅遊戲文件夾。Campfire 識別到常見嘅 Android 啟動器，亦可以選擇任意啟動器嘅 `.minecraft` 文件夾。Campfire 只讀取版本信息，並寫入自己安裝嘅模組。
- **使用帶模組加載器嘅版本**：語音模組需要 Fabric、Forge、NeoForge 或 Quilt。
- **重新啟動遊戲**：安裝語音模組後，需要重新啟動遊戲並進入世界，語音先會生效。

完整說明見[語音聊天](./voice)。

## 聯機設置

**設置** 標籤頁即係聯機設置，包含以下內容：

- **玩家**：玩家名稱同遊戲內名稱。
- **網絡**：容許中轉、隱藏我嘅 IP 地址、尋找房主嘅時限、識別剪貼板中嘅邀請碼，以及 **中轉服務器**。中轉服務器頁面可以測速、選擇內置服務器或添加自定義節點。
- **隱私**：顯示正版玩家嘅皮膚頭像、向其他玩家顯示軟件版本，以及重置設備標識。
- **遊戲**：遊戲文件夾。
- **房間**：房間設置同白名單。
- **診斷**：**聯機診斷** 逐項檢查系統、聯機組件、網絡連接、中轉服務器、本地端口同局域網世界，並提供處理建議；**聯機日誌** 記錄加入同創建房間嘅過程，可以直接分享俾其他人排查問題。

## 更新與隱私

- **公告**：啟動時獲取 Campfire 發佈嘅公告，可以喺 **應用設置** 中關閉 **接收公告**。
- **使用統計**：首次進入主界面時，Campfire 會詢問係咪發送匿名使用統計，默認唔發送。允許後每日最多發送一次，可以喺 **應用設置** 中關閉、查看下一次發送嘅內容或重置統計標識。
- **皮膚頭像**：房間內有正版玩家時，玩家列表顯示佢嘅皮膚頭像，可以喺 **設置** 中關閉 **顯示正版玩家嘅皮膚頭像**。
- **檢測更新**：默認關閉。喺 **應用設置** 中開啟後，Campfire 會喺啟動時檢查新版本；發現新版本時，點擊 **更新** 會喺瀏覽器中打開下載地址，應用本身唔會下載或安裝任何程序。
- Android 版嘅全部聯網行為見[聯網與安全](./security#android-版)。

## 常見問題

### 自動發現唔到我嘅世界

請確認已經喺遊戲中對局域網開放世界，並已喺首次啟動或系統設置中容許 Campfire 訪問局域網。使用流動數據或部分公共 Wi-Fi 時無法自動發現，請改用 **手動輸入端口**。

### 玩家進入世界後好快斷開

多數係系統喺後台限制咗 Campfire。請喺系統設置中容許 Campfire 後台運行，並關閉對佢嘅電池優化。

### 加入唔到房間

請先運行 **聯機診斷**。雙方網絡限制都較嚴時可能無法直連，可以喺聯機設置中容許中轉，或由網絡條件較好嘅一方擔任房主。其他問題見[常見問題](./faq)。
