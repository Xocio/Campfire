# 語音聊天

Campfire 藉助開源模組 Simple Voice Chat 為房間提供語音。房主開啟語音後，Campfire 會為遊戲安裝並啟用該模組，語音經聯機網絡加密傳輸，無需端口映射；房間內安裝同一模組嘅玩家進入世界後就可以相互交談。

## 開始之前

- 語音需要模組加載器：請使用 Fabric、Forge、NeoForge 或 Quilt 版本嘅遊戲，原版冇辦法使用。
- 玩家須擁有與房主遊戲版本及模組加載器相同嘅本機版本。
- 語音適用於由房主遊戲開放嘅局域網世界，專用服務器暫唔支持開啟語音。
- 語音默認關閉，僅喺房主開啟後提供。

## 房主：開啟語音

1. 創建房間後，喺多人聯機頁面嘅 **工具** 卡片中搵到 **語音**，按 **開啟**。
2. 若遊戲中尚未安裝該模組，Campfire 會從 Modrinth 下載適用於該遊戲版本與加載器嘅最新正式版，校驗後放入遊戲嘅模組文件夾；已停用嘅同一模組會被重新啟用。
3. 新裝嘅模組需要重新啟動遊戲先會生效。Campfire 會彈出提示，請關閉並重新啟動遊戲，進入同一個世界。

重新啟動遊戲期間，房間保持開啟，邀請碼唔變，房間內嘅玩家無需重新加入。10 分鐘內回到同一個世界，Campfire 會自動對局域網開放並恢復房間；未開啟自動對局域網開放時，請手動開放。

**語音** 一欄會顯示當前狀態：

| 狀態 | 說明 |
| --- | --- |
| 未開啟 | 按 **開啟** 後為遊戲安裝語音模組 |
| 喺度下載語音模組 | 喺度自 Modrinth 下載並校驗 |
| 已安裝，重新啟動遊戲並進入世界後生效 | 請重新啟動遊戲，房間會保持開啟 |
| 已開啟 | 遊戲中嘅語音服務已運行，安裝咗語音模組嘅玩家可相互交談 |

按 **關閉** 後，Campfire 立即停止轉發語音，房間內玩家嘅語音隨即中斷。模組仍保留喺遊戲中，唔再需要時可喺啟動器中自行移除。

## 玩家：安裝語音模組

房主開啟語音後，玩家嘅多人聯機頁面會喺 **工具 › 語音** 中提示安裝：

1. 按 **安裝**，確認要安裝嘅模組與目標版本。
2. Campfire 優先下載與房主完全相同嘅文件；Modrinth 未收錄時，改為適用於該遊戲版本嘅最新正式版。文件僅寫入與房主遊戲版本及加載器相同嘅本機版本嘅模組文件夾。
3. 啟動該版本嘅遊戲並進入房主嘅世界就可以交談；安裝時遊戲已喺運行嘅，請重新啟動遊戲。

| 狀態 | 說明 |
| --- | --- |
| 房主未開啟語音 | 房主開啟後先能使用 |
| 房主已開啟語音，將喺房主重新啟動遊戲後可用 | 房主嘅遊戲尚未加載語音模組 |
| 房主已開啟語音，為版本 … 安裝語音模組後就可以使用 | 按 **安裝** |
| 未搵到與房主遊戲版本及模組加載器相同嘅版本 | 請先喺啟動器中安裝相同嘅版本 |
| 本機 UDP 端口 … 已被佔用 | 請關閉佔用該端口嘅程序後重試 |
| 已就緒 | 進入房主嘅世界後就可以語音交流 |

進入世界後，按鍵、麥克風與音量均喺模組嘅設置界面中調整，默認按 **V** 打開。

## 喺聯機大廳中

提供語音嘅房間喺聯機大廳中帶有 **語音** 標籤，房間詳情中亦會註明，加入後喺房間頁面安裝語音模組就可以使用。

## 隱私

語音數據由模組喺玩家與房主之間傳輸，並經聯機網絡加密。Campfire 唔讀取、唔保存任何語音內容。房主僅喺語音服務運行時向房間開放其所用嘅一個 UDP 端口，關閉語音後立即撤銷。詳見[聯網與安全](./security#語音)。
