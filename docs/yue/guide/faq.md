# 常見問題

## 多人聯機

### 需要使用特定嘅啟動器嗎？

唔需要。Campfire 直接作用於喺度運行嘅遊戲，無論以何種啟動器、何種賬號類型啟動遊戲，都可以創建或加入房間。採用相同聯機協議嘅其他客戶端，亦能與 Campfire 用戶進入同一房間。

### 遊戲數據會經過誰嘅服務器？

遊戲數據唔經過 Campfire 嘅服務器。玩家之間優先點對點直連，聯機節點只負責幫助雙方互相發現；只有喺容許中轉且直連失敗時，數據先會經中轉節點傳輸。

### 加入時提示「無效會話」

房主以正版賬號開放局域網時，遊戲會校驗每位加入者嘅身份。請從多人遊戲列表底部嘅局域網世界中進入房間，而唔好通過「直接連接」輸入地址。若仍然出現此提示，可請房主改用離線賬號開放局域網。

### 未搵到房間，或一直喺尋搵房主

可先運行[聯機診斷](./room#聯機診斷)，佢會逐項檢查系統、聯機組件、網絡、中轉服務器與本地端口。隨後請依次檢查：

1. 邀請碼是否完整、正確；
2. 房主嘅房間是否仍處於開啟狀態；
3. 雙方是否至少啟用咗一個相同嘅中轉服務器。若任何一方停用咗全部內置服務器，雙方必須填寫相同嘅自定義節點；
4. 若房主使用其他客戶端，雙方同樣需要能連接到相同嘅節點。

### 提示「房間人數已滿」

房主喺房間設置中設定咗人數上限，房間內嘅玩家已達到上限。可稍後重試，或聯繫房主調整，見[房間設置](./room#房間設置)。

### 進入世界時提示缺少模組或模組版本唔一致

房主開啟模組同步後，可喺多人聯機頁面嘅 **工具 › 模組同步** 中一鍵將本機模組調整為與房主一致，見[模組同步](./mods)。

### 冇辦法開啟或使用語音

- 語音需要模組加載器，原版遊戲冇辦法使用，請改用 Fabric、Forge、NeoForge 或 Quilt 版本。
- 房主安裝語音模組後，須重新啟動遊戲並進入同一個世界，語音先會生效。
- 玩家須擁有與房主遊戲版本及加載器相同嘅本機版本，併為其安裝語音模組。
- 提示本機 UDP 端口已被佔用時，請關閉佔用該端口嘅程序後重試。

詳見[語音聊天](./voice)。

### 存檔出咗問題，能恢復嗎？

開啟 **開房前備份存檔**（默認開啟）時，每次創建房間都會備份喺度遊玩嘅世界。可喺 **工具 › 存檔備份** 中將任一備份還原為新世界，見[存檔備份](./room#存檔備份)。

### 搵到咗房主，但冇辦法建立直連

多見於雙方網絡限制均較嚴嘅情況，例如同為 NAT4。可以喺聯機設置中開啟 **直連失敗時容許通過中轉節點連接**，或由網絡條件更好嘅一方擔任房主。雙方都具備 IPv6 時，直連成功率最高。

### 房主睇唔到我，或連接後冇響應

若你開啟咗 **隱藏我嘅 IP 地址**，所有數據都必須經由中轉節點傳輸，房主亦需要容許中轉連接。此外，房主可能已關閉房間，或網絡暫時唔穩定，請稍後重試。

### 遊戲內未顯示歡迎消息與 Tab 信息，或未自動對局域網開放

呢啲功能依賴附加到房主遊戲中嘅組件，支持 1.7.2 及以上嘅原版與沿用官方名稱嘅加載器。若房主所用嘅 Java 運行時唔提供附加功能，或遊戲環境經 Fabric、Quilt 等加載器重映射，則需手動對局域網開放，房間信息亦將退回僅喺局域網列表中顯示，遊戲連接唔受影響。具體原因記錄喺房主電腦嘅 `%LocalAppData%\Campfire\agent.log` 中。

### 房間未出依家聯機大廳中

請確認已喺多人聯機頁面按 **公開到聯機大廳**，且左下角顯示 **已公開到聯機大廳**。房間名稱含有唔宜公開嘅內容、房間遭多名玩家舉報，或同一網絡中公開嘅房間過多時，均冇辦法公開，頁面會說明具體原因，見[公開時嘅提示](./lobby#公開時嘅提示)。

### 聯機組件下載失敗

請檢查網絡連接。若喺度使用代理或加速器，可以嘗試將其關閉後重試。

### 提示缺少 Windows 7 更新

喺 Windows 7 上使用多人聯機，需要通過 Windows 更新安裝 KB3063858 與 KB4474419 並重新啟動。冇辦法使用 Windows 更新時，可以喺 Microsoft Update 目錄中按編號手動下載。

### 點樣查看詳細嘅失敗原因？

可先運行[聯機診斷](./room#聯機診斷)。失敗頁面仲提供 **查看聯機日誌** 按鈕。日誌保存在 `%LocalAppData%\Campfire\Link\link.log`，反饋問題時請一併附上。

## 地圖

### 導入嘅地圖未出依家遊戲中

請確認所啟動嘅正是導入時選擇嘅版本。啟用版本隔離嘅啟動器會將存檔保存在版本文件夾中；遊戲啟動後，Campfire 依據運行中嘅遊戲確認存檔位置，如有不同，將自動遷移地圖。如仍未出現，可喺導入頁面按 **打開存檔文件夾** 查看地圖所在位置。

### 導入時未列出所需嘅遊戲版本

Campfire 會查搵默認嘅 `.minecraft` 文件夾、啟動器旁嘅 `.minecraft` 文件夾，以及啟動器設置中記錄嘅遊戲文件夾。遊戲位於其他位置時，請按 **添加遊戲文件夾**。

### 打開地圖後命令方塊或紅石失效

將 1.13 之前嘅地圖導入 1.13 及以後嘅版本時，遊戲會轉換地圖格式，命令與紅石常因此失效。請優先選擇標註為 **與地圖版本相同** 嘅版本。

## 啟動器修復

### 修復安全嗎？

Campfire 只修改與下載、安裝直接相關嘅少數方法，唔添加任何聯網行為。修復結果先喺內存中生成並逐項校驗，通過後才寫入磁盤；任一步驟失敗，原文件都保持唔變。原文件始終以 `.bak` 備份。詳見[工作原理](./how-it-works#啟動器修復)。

### 提示「暫唔支持修復」

說明該啟動器嘅代碼結構與已知版本不同，Campfire 冇辦法確認修改位置。此時唔會做任何修改。可以喺 [GitHub Issues](https://github.com/Xocio/Campfire/issues) 中反饋啟動器嘅版本。

### 寫入文件失敗

啟動器可能仍喺運行，或位於 `Program Files` 等受保護嘅文件夾。請關閉啟動器後重試；仍然失敗時，以管理員身份運行 Campfire。

### 修復後啟動器仲能更新嗎？

修復會停用啟動器嘅自動更新，以免更新後功能再次被關閉。需要升級時，請手動下載新版啟動器，再運行 Campfire 檢測是否需要修復。

### 點樣撤銷修復？

喺啟動器修復工具中按 **還原**；或刪除修復後嘅啟動器，再將 `.bak` 文件改回原名。

## 其他

### Campfire 是否可能被遠程控制？

唔會。Campfire 自服務器接收嘅僅為文字與列表數據，冇辦法更改設置、執行命令或啟動程序；只有通過簽名校驗嘅更新與哈希一致嘅聯機組件先會被運行。全部聯網行為與風險邊界見[聯網與安全](./security)。

### 殺毒軟件報毒

修改其他程序文件嘅工具偶爾會被誤判。Campfire 完全開源，可以審閲源代碼並[自行構建](https://github.com/Xocio/Campfire#從源碼構建)。官方發佈嘅文件可以通過[下載頁](/yue/download)中嘅 SHA-256 核對。

### 關閉窗口後 Campfire 去哪咗？

若開啟咗 **關閉窗口時保留喺通知區域**，Campfire 會繼續喺通知區域中運行，房間保持開啟。按圖標就可以返回窗口。Windows 11 可能將圖標收進任務欄右側嘅 **^** 溢出菜單中。

### 再次打開程序時冇出現新窗口

同一用戶會話中只運行一個 Campfire。再次打開時，已喺運行嘅窗口會被切換到前台；若佢隱藏喺通知區域中，亦會被重新顯示。

### 點樣反饋問題？

請喺 [GitHub Issues](https://github.com/Xocio/Campfire/issues) 中提交，並儘量附上系統版本、操作步驟，以及聯機日誌或截圖。

亦可以加入 [Telegram 羣聊](https://t.me/CampfireGroup) 交流，或關注 [Telegram 頻道](https://t.me/McCampfire) 獲取更新動態。
