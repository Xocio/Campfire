# 聯網與安全

本頁逐項說明 Campfire 嘅聯網行為：連接嘅對象、發生嘅時機、傳輸嘅內容、能否關閉，以及每一項點解唔會危及你嘅電腦與賬號。文中嘅每一條陳述均可喺源代碼中核對，對應位置見[自行核對](#自行核對)。

## 設計原則

以下原則由代碼保證，並作為長期唔變嘅設計約束：

1. **遠程內容冇辦法控制本機。** Campfire 自服務器接收嘅僅為文字、版本號與列表數據，例如公告、更新說明與聯機大廳嘅房間列表。呢啲內容冇辦法更改任何設置，冇辦法執行命令，冇辦法指定本機路徑，亦冇辦法啟動任何程序。
2. **Campfire 自身僅下載並運行兩類程序，且均經校驗。**
   - **Campfire 自身嘅更新**：須帶有 Campfire 發佈密鑰嘅數字簽名，且文件嘅實際版本須與聲明一致，否則唔予安裝。
   - **聯機組件**：每個文件嘅 SHA-256 均固定於程序之中，任何一個字節嘅差異都會導致其被丟棄。

   模組同步會將模組文件寫入所選版本嘅模組文件夾。呢啲文件由遊戲加載，Campfire 本身唔運行佢哋，且僅喺你確認後寫入，詳見[模組同步](#模組同步)。
3. **無需管理員權限。** Campfire 以普通權限運行，唔安裝驅動，唔創建虛擬網卡，唔寫入系統目錄。
4. **唔觸及賬號。** Campfire 唔讀取、唔保存、唔上傳任何登錄憑據。
5. **啟動器修復完全離線。** 修復僅喺本機修改文件，唔聯網，都唔為啟動器添加任何聯網行為。
6. **源碼構建唔連接 Campfire 服務。** 服務地址僅喺正式版構建時寫入。自行構建嘅版本唔具備更新檢查、公告、使用統計、聯機大廳、在線地圖與 CurseForge 模組查詢，邀請碼聯機唔受影響。

## Campfire 服務

正式版連接 `https://api.mccampfire.top`，該服務由 Cloudflare 提供服務與安全防護。所有請求均經 HTTPS 加密，並以 `Campfire/版本號` 作為客戶端標識。

### 更新與公告

- **發送**：唔發送任何內容，都唔攜帶任何設備標識，所有用戶獲得嘅內容完全相同。
- **接收**：最新版本號、更新說明、下載地址與簽名地址、公告文字，以及檢查間隔。
- **約束**：
  - 公告僅能呈現文字。公告按鈕只能打開 `https://` 網頁，且僅喺用戶按時打開，唔可以啟動程序。
  - 檢查間隔被限定喺 1 小時至 7 天之間。
  - 服務器冇辦法藉此更改任何設置。

### 更新

1. 下載新版本及其簽名後，Campfire 以程序內置嘅公鑰校驗簽名，並核對文件嘅實際版本號，以防舊版本被冒充為新版本。
2. 校驗通過後，Campfire 徵得同意，再替換程序文件並重新啟動。
3. 未通過校驗嘅文件將被直接丟棄。

因此，即便服務器或下載鏡像為他人所控制，都冇辦法令 Campfire 安裝經過篡改嘅程序。

::: info 關於必須更新
當舊版本存在嚴重問題時，服務器可將新版本標記為必須更新。只有喺簽名正確嘅新版本**確已下載並通過校驗**後，Campfire 先會要求更新後再繼續使用。若下載或校驗失敗，Campfire 照常可用，任何服務器消息都冇辦法阻止佢啟動。
:::

### 使用統計

僅喺授權後發送，每日至多一次，內容僅限：

- 隨機生成嘅統計標識，與聯機所用嘅設備標識無關，可隨時重置；
- 軟件版本、Windows 版本與系統位數、.NET Framework 版本及界面語言；
- 各項功能嘅使用次數，例如創建房間與加入房間。

統計唔包含 IP 地址、遊戲賬號與 UUID、玩家名稱、房間與邀請碼、文件路徑、硬件序列號及網卡地址。服務器依據網絡來源推斷大致嘅國家與省份，唔保存 IP 地址。下一次發送嘅完整內容可喺 **設置 › 常規 › 查看發送內容** 中查看。詳見[更新與隱私](./updates-privacy#使用統計)。

### 聯機大廳

- **瀏覽**：僅獲取房間列表，唔發送任何內容。
- **公開房間**：發送房間名稱、標籤、房主名稱、遊戲版本、世界名稱、人數、是否提供語音、邀請碼、可選嘅房間密碼與圖標，以及一個大廳專用嘅隨機編號。該編號與設備標識、統計標識均無關聯。房間開啟期間每隔數分鐘更新一次人數，房間關閉時隨即撤下。
- **加入**：向服務器領取該房間嘅邀請碼；設有密碼嘅房間會一併提交所輸入嘅密碼。
- **舉報**：僅發送房間編號與舉報原因。

服務器僅保存房間密碼嘅摘要，唔保存原文；IP 地址僅以加鹽摘要嘅形式保存，用於限制發佈頻率與處理違規。大致省份可選擇唔予顯示。取消公開或關閉房間後，房間即刻自大廳移除，相關記錄於一天內刪除。

大廳中嘅房間由其他玩家公開。加入陌生玩家嘅房間，與加入任何陌生嘅 Minecraft 服務器無異。

### 在線地圖

- 瀏覽與搜索時，Campfire 服務代為查詢 CurseForge 嘅地圖目錄，僅傳送搜索詞與篩選條件。
- 地圖文件與預覽圖僅從 CurseForge 嘅文件服務器 `forgecdn.net` 下載，其餘地址一概拒絕，下載完成後以 SHA-1 校驗。
- 地圖屬於存檔數據而非程序。導入時僅解壓至所選嘅存檔文件夾，任何試圖寫入該文件夾之外嘅文件都會被拒絕。

## 多人聯機

### 聯機組件

多人聯機以開源網絡組件 EasyTier 2.6.4 為基礎。首次聯機時，Campfire 依次探測以下地址，並選擇最快者下載：

- `gitee.com`、`github.com`：官方發佈頁；
- `ghfast.top`、`gh-proxy.com`：GitHub 下載加速服務。

三個文件嘅 SHA-256 均寫定於 Campfire 嘅代碼之中，與官方發佈完全一致。無論來自哪一地址，內容唔符嘅文件既唔會被保存，都唔會被運行。加速服務僅能獲知你嘅 IP 地址以及你喺度下載該組件。

聯機組件以普通權限運行，唔安裝虛擬網卡，都唔為其他網絡轉發流量。房主僅向房間開放遊戲與房間服務所需嘅端口；開啟語音後，另開放房主遊戲中語音服務所用嘅一個 UDP 端口。加入者唔開放任何端口，房間內嘅玩家冇辦法藉此訪問你電腦上嘅其他服務。

### 節點與連接

- **聯機節點**用於幫助同一房間嘅玩家互相發現。內置公共節點為 EasyTier 社區節點 `225284.xyz`、`easytier.weiai.org.cn`、`et.basd1.de`、`et.sumnight.top`、`et.chinokou.cn`、`et-public.lctn.top`、`et.南梁.com`、`etnode.zkitefly.eu.org`，以及一個以 IP 地址接入嘅重慶移動節點。各節點可喺 聯機設置 › 中轉服務器 中逐一啟用或停用，亦可僅使用自行填寫嘅節點。
- **測速**：Campfire 以一個名稱隨機、唔接受任何連接嘅臨時網絡逐一連接內置節點，以測得往返延遲，測完即斷開。測速唔傳輸任何遊戲數據，節點運營方僅能獲知你嘅 IP 地址與連接時間。標題欄嘅指示燈據此顯示節點狀態。
- Campfire 優先喺玩家之間建立直連。為此，聯機組件可能向公共 STUN 服務探測網絡類型，並可能通過 UPnP 喺路由器上建立臨時嘅端口映射。
- 僅喺容許中轉且直連失敗時，遊戲數據先會經中轉節點傳輸。
- 遊戲數據喺玩家之間加密傳輸，節點冇辦法讀取。節點運營方可獲知你嘅 IP 地址與連接時間。
- 開啟 **隱藏我嘅 IP 地址** 後，全部數據均經中轉節點傳輸，其他玩家無從得知你嘅 IP 地址，但中轉節點嘅運營方仍可獲知。

相關選項見[網絡與隱私](./network)。

### 房間內共享嘅信息

房間內嘅其他玩家可以睇到你嘅玩家名稱、設備標識，以及你是否使用正版賬號；喺開啟相應選項時，仲可睇到你嘅正版 UUID 與 Campfire 版本。設備標識為隨機生成，可隨時重置。

作為房主時，若開啟模組同步，房間內嘅玩家仲可睇到你嘅遊戲版本、模組加載器，以及模組文件夾中各模組嘅文件名、名稱、版本、SHA-1 與 CurseForge 指紋。模組同步可喺聯機設置中以 **容許玩家同步我嘅模組** 設定，亦可喺房間頁面隨時開啟或關閉，關閉後立即生效。

### 皮膚頭像

開啟 **顯示正版玩家嘅皮膚頭像** 後，Campfire 以玩家嘅 UUID 向 `sessionserver.mojang.com` 查詢皮膚，並從 `textures.minecraft.net` 下載皮膚圖片。關閉後唔再查詢。

### 遊戲內組件

Campfire 會將一個小型 Java 組件附加到**房主本機**喺度運行嘅遊戲，用於自動對局域網開放、呈現歡迎消息與 Tab 信息。該組件唔聯網，唔啟動程序，都唔加載任何外部代碼。

1.14.4 至 1.21.11 嘅遊戲需要 Mojang 官方嘅名稱映射表。映射表自 `piston-data.mojang.com` 下載，冇辦法連接時改由國內鏡像 `bmclapi2.bangbang93.com` 提供，並以遊戲自帶版本文件中嘅 SHA-1 校驗。映射表僅為名稱對照文本，並非程序。

### 模組同步

加入房間後，Campfire 向房主請求其模組列表，並與本機所選版本比對。比對僅讀取本機文件，唔聯網。開始同步後：

- **官方源**：先以房主列出嘅 SHA-1 向 `api.modrinth.com` 查詢，Modrinth 未收錄嘅再將房主列出嘅 CurseForge 指紋發送至 Campfire 服務，由其代為查詢 CurseForge。僅接受 `cdn.modrinth.com` 與 `forgecdn.net` 嘅 HTTPS 下載地址，且只採用與房主完全相同嘅文件。兩項查詢均僅發送文件哈希或指紋。
- **房主**：官方源未收錄或作者唔准第三方下載嘅文件，可經聯機網絡自房主處獲取。獲取前 Campfire 會告知文件數量並徵得同意。房主僅能按列表中嘅 SHA-1 提供文件，玩家冇辦法藉此讀取房主模組文件夾以外嘅任何文件；房主可喺聯機設置中關閉 **容許玩家從我呢度下載模組**。
- **校驗**：無論來自哪一來源，文件嘅大小與 SHA-1 均須與房主所列一致，否則即被丟棄。全部文件下載並校驗完畢後，先會改動模組文件夾。
- **寫入範圍**：僅寫入所選版本嘅模組文件夾，文件名唔得包含路徑。被替換或移除嘅模組移至 Campfire 數據目錄中嘅備份文件夾，唔會被刪除。下載嘅文件緩存 14 天。

模組係隨遊戲運行嘅程序。自房主處獲取模組，與接受房主發送嘅整合包無異，請僅喺信任房主時使用。

### 語音

語音由開源模組 Simple Voice Chat 提供，Campfire 負責安裝該模組並使其語音數據經聯機網絡傳輸。

- **房主開啟語音**：若房主遊戲嘅模組文件夾中冇該模組，Campfire 向 `api.modrinth.com` 查詢適用於該遊戲版本與模組加載器嘅最新正式版，僅自 `cdn.modrinth.com` 下載並以 SHA-1 校驗；已停用嘅同一模組會被重新啟用。若該模組嘅客戶端設置關閉咗單人與局域網世界中嘅語音，Campfire 會將其重新開啟。新裝嘅模組喺遊戲重新啟動後生效。
- **端口**：僅當房主遊戲嘅語音服務喺度運行時，房主才向房間開放其所用嘅 UDP 端口。該端口取自遊戲日誌，並核對確由該遊戲佔用；關閉語音後立即撤銷。
- **玩家安裝模組**：玩家按 **安裝語音模組** 並確認後，Campfire 優先下載與房主完全相同嘅文件，Modrinth 未收錄時改為適用於該遊戲版本嘅最新正式版。文件僅寫入與房主遊戲版本及加載器相同嘅本機版本嘅模組文件夾。
- **語音數據**：語音數據由模組喺玩家與房主之間傳輸，並經聯機網絡加密，Campfire 唔讀取、唔保存任何語音內容。

## Android 版

Android 版遵循上述設計原則，以 `Campfire-Android/版本號` 作為客户端標識。佢嘅聯網行為如下，除此之外冇其他聯網行為：

| 功能 | 連接對象 | 時機 | 能否關閉 |
| --- | --- | --- | --- |
| 公告 | Campfire 服務 | 啟動時，此後每隔 6 小時 | 可以喺設置中關閉 **接收公告** |
| 檢查更新 | Campfire 服務 | 啟動時，或者喺設置中點擊 **檢測更新** 時 | 默認關閉 |
| 聯機大廳 | Campfire 服務 | 瀏覽大廳、加入或舉報房間時，以及房間公開至大廳期間 | 唔使用就唔連接；房間關閉後自動從大廳移除 |
| 使用統計 | Campfire 服務 | 授權後每日至多一次 | 默認唔發送，授權後可以隨時喺應用設置中關閉 |
| 皮膚頭像 | Mojang 官方服務 | 房間內有正版玩家時 | 可以喺 設置 › 隱私 中關閉 |
| 多人聯機 | 聯機節點同房間內嘅其他玩家 | 房間開啟期間 | 節點同中轉均可配置 |
| 節點測速 | 內置聯機節點 | 開啟自動選擇節點時於啟動後進行；打開節點頁面、點擊測試或運行聯機診斷時 | 關閉自動選擇節點後，啟動時唔再進行 |
| 語音 | Modrinth | 房主開啟語音並安裝語音模組時 | 默認關閉 |
| 打開網頁 | 系統瀏覽器 | 僅喺點擊鏈接或按鈕時 | — |

- **更新**： Android 版只讀取版本號、更新說明同下載地址。點擊下載後由系統瀏覽器打開 HTTPS 下載地址，應用自身唔下載、唔安裝任何程序。
- **聯機組件**：隨安裝包一同提供，唔另行下載。兩個原生庫嘅 SHA-256 記錄於 `src/android/easytier/prebuilt.txt`，構建時逐一校驗。
- **語音模組**：僅自 `cdn.modrinth.com` 嘅 HTTPS 地址下載，SHA-1 須同 Modrinth 所列一致，隨後寫入你所授權嘅遊戲文件夾中嘅模組文件夾。
- **遊戲文件夾**：僅喺你通過系統文件選擇器授權後讀寫，範圍限於所授權嘅文件夾。
- **使用統計**：內容為隨機統計標識（同聯機及大廳使用嘅標識無關）、應用版本、 Android 版本、處理器架構、界面語言同功能使用次數（啟動、創建房間、加入房間、公開到大廳、由大廳加入）。大致地區由服務器依據網絡來源推斷，唔留存 IP 地址。喺 應用設置 › 隱私 中可以查看下一次發送嘅完整內容，或重置統計標識。
- **公開到大廳**：發送房間名稱、介紹、標籤、房主名稱、人數、遊戲版本、世界名稱、是否提供語音同邀請碼。邀請碼只會喺其他玩家點擊加入時由服務發放；設咗密碼時，服務只保存密碼嘅哈希值。
- **皮膚頭像**：只以正版玩家嘅 UUID 向 `sessionserver.mojang.com` 查詢，皮膚只從 `textures.minecraft.net` 下載，喺本機緩存一日。
- **唔具備嘅功能**： Android 版冇在線地圖、模組同步同遊戲內組件，唔發送亦唔下載相應內容。
- **源碼構建**：未傳入服務地址嘅構建唔連接 Campfire 服務，公告、更新檢查、使用統計同聯機大廳均唔出現，邀請碼聯機唔受影響。

## 風險邊界

即便某一方為他人所控制，其影響亦有明確嘅邊界：

| 受控嘅一方 | 影響範圍 | 冇辦法做到 |
| --- | --- | --- |
| Campfire 服務 | 顯示唔實嘅公告文字與網頁鏈接；篡改大廳列表與地圖目錄；提示一個冇辦法安裝嘅「更新」 | 安裝或運行任何程序；更改你嘅設置；讀取你嘅文件 |
| 下載鏡像或加速服務 | 致使下載失敗 | 替換更新或聯機組件，簽名與哈希校驗會將其拒絕 |
| 聯機節點或中轉節點 | 獲知你嘅 IP 地址與連接時間；致使連接失敗 | 讀取遊戲數據；訪問房主遊戲以外嘅端口 |
| 房間內嘅其他玩家 | 與常規 Minecraft 聯機相同嘅遊戲內互動 | 訪問你電腦上嘅其他服務與文件 |
| 房主（模組同步） | 提供含惡意代碼嘅模組，經你確認後由遊戲運行 | 未經你確認寫入文件；寫入模組文件夾以外嘅位置；讀取你嘅文件 |

## 隱私選項

- **僅使用啟動器修復**：修復功能本身唔聯網；亦可喺 **設置 › 常規** 中關閉 **啟動時檢查更新與公告**。
- **唔發送使用統計**：喺首次詢問時拒絕，或喺 **設置 › 常規** 中關閉 **發送匿名使用統計**。
- **聯機時保護隱私**：喺聯機設置中開啟 **隱藏我嘅 IP 地址**，關閉 **顯示正版玩家嘅皮膚頭像** 與 **向其他玩家顯示軟件版本**，作為房主時關閉 **容許玩家同步我嘅模組**，或僅使用自建節點。
- **完全唔連接 Campfire 服務**：[從源代碼構建](https://github.com/Xocio/Campfire#從源碼構建)。
