# 模組同步

加入房間後，模組同步會比對本機與房主嘅遊戲版本同模組，列出唔一致之處，並一鍵將本機嘅模組調整為與房主相同。

## 房主：提供模組列表

模組同步默認開啟。房間開啟後，可喺多人聯機頁面嘅 **工具 › 模組同步** 中隨時 **開啟** 或 **關閉**；關閉後立即停止提供模組列表與文件。亦可喺 **設置 › 聯機 › 模組** 中設定：

| 選項 | 說明 |
| --- | --- |
| **容許玩家同步我嘅模組** | 房間內嘅玩家可查看你嘅遊戲版本、模組加載器，以及各模組嘅名稱與版本，並據此同步 |
| **容許玩家從我呢度下載模組** | 官方源未收錄嘅模組經聯機網絡自你嘅電腦傳送，會佔用上傳帶寬。僅模組文件夾中列出嘅文件可被下載 |

## 玩家：同步模組

1. 加入房間後，喺多人聯機頁面嘅 **工具 › 模組同步** 中按 **同步**，打開模組同步頁面。
2. 頁面上方顯示房主嘅遊戲版本、加載器與模組數量。
3. 喺 **本機版本** 中選擇與房主相同嘅已安裝版本。未列出時，可按 **添加遊戲文件夾**；仍未搵到時，請先喺啟動器中安裝該版本。
4. 查看差異列表：

   | 標記 | 含義 |
   | --- | --- |
   | **缺少** | 房主安裝了，本機冇 |
   | **版本不同** | 雙方都有，版本唔一致 |
   | **房主未安裝** | 本機有，房主冇。勾選 **移除房主未安裝嘅模組** 後將其移入備份文件夾 |

   小地圖、光影等僅需一方安裝嘅模組唔計入差異。

5. 選擇 **下載來源**，按 **同步模組**。

| 下載來源 | 說明 |
| --- | --- |
| **優先官方源** | 自 Modrinth 與 CurseForge 下載與房主完全相同嘅文件，官方源未收錄或唔准第三方下載嘅再自房主獲取 |
| **僅官方源** | 只從 Modrinth 與 CurseForge 下載，冇辦法獲取嘅模組會喺完成後列出，需自行安裝 |
| **全部從房主獲取** | 全部文件經聯機網絡自房主嘅電腦傳送 |

::: warning 請僅喺信任房主時自房主獲取模組
模組係隨遊戲運行嘅程序。需要自房主獲取文件時，Campfire 會先告知文件數量並徵得同意。
:::

## 安全保障

- 無論來自哪一來源，文件嘅大小與 SHA-1 均須與房主所列一致，否則即被丟棄。
- 全部文件下載並校驗完畢後，先會改動模組文件夾。
- 被替換或移除嘅模組移入備份文件夾，唔會被刪除，可喺完成後按 **打開備份文件夾** 搵回。
- 房主只能按列表提供模組文件夾中嘅文件，玩家冇辦法藉此讀取房主嘅其他文件。

更完整嘅說明見[聯網與安全](./security#模組同步)。

## 常見提示

| 提示 | 處理 |
| --- | --- |
| 房主未開啟模組同步 | 請房主喺 **工具 › 模組同步** 中開啟 |
| 未搵到與房主相同嘅遊戲版本 | 先喺啟動器中安裝與房主相同嘅版本，再返回此頁 |
| 該版本嘅遊戲喺度運行 | 關閉遊戲後再同步 |
| 模組文件夾中嘅文件正被佔用 | 關閉遊戲後重試 |
| 房主未提供該文件 | 房主可能已關閉模組下載或更換咗模組 |
| 下載嘅文件與房主嘅文件唔符，已丟棄 | 請重試，或改用其他下載來源 |
| 已離開房間，冇辦法再從房主處獲取模組 | 重新加入房間後再同步 |
