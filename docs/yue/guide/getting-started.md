# 安裝與上手

## 準備

### 系統要求

- Windows 7 SP1、8、8.1、10 或 11。
- .NET Framework 4.8。Windows 10 與 11 已內置；Windows 7 與 8 如未安裝，請從[微軟官方網站](https://dotnet.microsoft.com/download/dotnet-framework/net48)下載。
- 喺 Windows 7 上使用多人聯機，仲需通過 Windows 更新安裝 **KB3063858** 與 **KB4474419** 並重新啟動。冇辦法使用 Windows 更新時，可喺 Microsoft Update 目錄中按編號手動下載。

### 下載

前往[下載頁](/yue/download)獲取最新版本。中國大陸用戶建議使用國內直鏈；亦可以從 [GitHub Releases](https://github.com/Xocio/Campfire/releases/latest) 下載。

喺手機或平板上玩 Minecraft Java 版時，請使用[Android 版](./android)。

## 首次運行

1. 將 `Campfire.exe` 放到任意文件夾並雙擊運行。若需使用啟動器修復，建議將其放喺啟動器所在嘅文件夾中，Campfire 會自動識別。
2. 首次啟動時會出現新手引導，用約半分鐘介紹主頁、地圖、工具與設置。可隨時跳過，之後喺 **設置 › 關於** 中再次查看。
3. 正式版會詢問是否發送匿名使用統計。該選項完全自願，拒絕唔影響任何功能，詳見[更新與隱私](./updates-privacy)。

::: tip 單實例運行
同一 Windows 用戶會話中只會運行一個 Campfire。再次打開程序時，已喺運行嘅窗口會被切換到前台，房間唔受影響。
:::

## 第一次聯機

以下為最簡流程，完整說明見[創建與加入房間](./multiplayer)。

**房主**

1. 喺 **主頁** 按 **創建房間**。
2. 啟動遊戲並進入單人世界，Campfire 會自動將其對局域網開放。
3. 房間隨即創建，邀請碼複製到剪貼板，發送畀好友就可以；亦可將房間公開至[聯機大廳](./lobby)。

**好友**

1. 複製房主發來嘅邀請碼後打開 Campfire，主頁將提示是否加入該房間；亦可喺 **主頁** 按 **加入房間** 並粘貼，或喺 **聯機大廳** 中選擇房間。
2. 連接完成後，喺遊戲嘅 **多人遊戲** 列表底部搵到房間條目，雙擊進入。

::: warning 首次聯機需下載聯機組件
第一次創建或加入房間時，Campfire 會下載約 14 MB 嘅聯機組件，並逐個文件校驗完整性。Windows 防火牆可能詢問是否容許其訪問網絡，選擇 **容許** 有助於建立直連。
:::

## 第一次修復啟動器

1. 關閉啟動器。
2. 打開 Campfire，喺 **工具** 中選擇 **啟動器修復工具**。Campfire 會自動查搵同一文件夾中嘅啟動器，亦可以按 **選擇文件** 或直接將啟動器拖入窗口。
3. 查看 **修復內容** 中各項嘅狀態，確認後按 **一鍵修復**。

修復完成後就可以正常啟動。原文件以 `.bak` 為後綴備份喺同一文件夾中，隨時可通過 **還原** 恢復。詳見[啟動器修復](./launcher-repair)。

## 數據位置

Campfire 嘅設置、聯機組件、日誌與緩存默認保存在 `%LocalAppData%\Campfire`。首次啟動時可以選擇其他位置，之後亦可以喺 **設置 › 常規 › 存儲位置** 中更改，已有數據會自動轉移。更改後默認文件夾中只保留一個記錄位置嘅小文件，下文嘅路徑相應變為所選文件夾。程序文件本身可以隨意移動或替換，唔會影響已保存嘅設置。

| 路徑 | 內容 |
| --- | --- |
| `settings.ini` | 全部設置 |
| `EasyTier\` | 聯機組件 |
| `Link\link.log` | 聯機日誌，用於排查問題 |
| `Link\blocked.json` | 房主嘅黑名單 |
| `Link\heads\` | 正版玩家皮膚頭像緩存，保留一天 |
| `Link\rooms.txt` | 最近房間與常用房間嘅記錄 |
| `backups\worlds\` | 開房前嘅存檔備份，每個世界保留最近 5 份 |
| `backups\mods\` | 模組同步時被替換或移除嘅模組 |
| `downloads\mods\` | 模組同步下載嘅文件，緩存 14 天 |
| `agent.log` | 遊戲內組件嘅日誌 |
| `mappings\` | 遊戲內組件使用嘅 Mojang 名稱映射表 |
| `downloads\maps\` | 下載嘅地圖文件，一週未使用後自動刪除 |

喺 **聯機設置 › 數據** 中可以直接打開該文件夾或備份文件夾，或刪除聯機組件以便下次重新下載。
